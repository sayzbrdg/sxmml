= sxmml 入門と目的別手順

この手順は Gauche 0.9.15 で sxmml を使い始める人向けです。最初の取得と変換は link:../README.md#最初の変換[README] を参照してください。以下は導入済みの `sxlc` が使えるシェルで実行します。入力ファイルは作業用ディレクトリに保存してください。

[[scheme-で音符列を作る]]
== Scheme で音符列を作る

次を `phrase.sxl` に保存します。

[source,scheme]
----
(define notes (map (lambda (name) (string-append name "8"))
                   '("c" "d" "e" "f")))
(mml G notes "r8")
----

[source,console]
----
sxlc -m pmd phrase.sxl
iconv -f CP932 -t UTF-8 phrase.mml
----

`notes` の値は文字列のリスト `("c8" "d8" "e8" "f8")` です。`mml` はその順に音符を並べ、最後に `r8` を加えます。

`phrase.mml` が生成され、G トラックの合計は 60 tick と表示されます。使用できる音符と音長は xref:sxmml-mml-manual.adoc[MML コマンドマニュアル]を参照してください。

[[リズムを加える]]
== リズムを加える

次を `beat.sxl` に保存します。

[source,scheme]
----
(mml G "l8 c d e f")
(rhythm L "V10 vb8 @b8 r8")
----

[source,console]
----
sxlc -m pmd beat.sxl
iconv -f CP932 -t UTF-8 beat.mml
----

G と L のトラックがそれぞれ 48 tick と 24 tick と表示されます。

L は PMD モードのリズム用トラックです。`@b8` でバスドラムを鳴らして八分音符分進み、`r8` でさらに同じ長さだけ休みます。楽器別音量や反復などは xref:sxmml-mml-manual.adoc#rhythm-mml[リズム MML]を参照してください。

[[登録する-mml-を加工する]]
== 登録する MML を加工する

次を `repeat.sxl` に保存します。

[source,scheme]
----
(mml-repeat G 2
  ((mml G "c8d8")))
----

[source,console]
----
sxlc -m pmd -O 0 repeat.sxl
iconv -f CP932 -t UTF-8 repeat.mml
----

`mml-repeat` は G トラックで `c8d8` を2回繰り返します。`-O 0` で変換すると反復記法が残り、合計は 48 tick と表示されます。一部のトラックだけに脱出位置を置く例や、反復後に音を加えて遅れを調整する例は、xref:sxmml-reference-manual.adoc#mml-repeat[公開機能の説明]を参照してください。

[[最適化水準を比較する]]
== 最適化水準を比較する

最初の例で作った `phrase.sxl` を PMD 向けに変換します。`-o` でそれぞれ別の出力先を指定すると、生成した MML を並べて比較できます。

[source,console]
----
sxlc -m pmd -O 0 -o phrase-O0.mml phrase.sxl
sxlc -m pmd -O 1 -o phrase-O1.mml phrase.sxl
sxlc -m pmd -O 2 -o phrase-O2.mml phrase.sxl
----

PMD では、`-O 0` は通常の最適化を省きます。`-O 1` は連続する設定命令を整理し、`-O 2` はさらに設定の状態を追跡して冗長な再指定を取り除き、隣り合う休符をまとめます。
このフレーズには整理できる設定命令や連続する休符がないため、3ファイルとも G トラックの出力は `G l%12o4cdefr` です。命令数が減る入力例は xref:verification.adoc#r-03-オブジェクト数の削減[オブジェクト数の比較]を参照してください。

[[出力とエラーを確認する]]
== 出力とエラーを確認する

`sxlc -l` でモードの正式名と別名を確認できます。`pmd` は `pmd-source`、`pmd3` は `pmd3-source` の別名です。変換結果には正式名が表示されます。
`-m` を省く場合は、ソース内で `(sxmml-mode pmd)` のように指定してください。両方で指定すると `-m` が優先され、どちらにも指定がなければエラーになります。

出力先は次の順で決まります。

. `-o` で指定したパス。
. ソースで `sxmml-default-output-path-set!` に指定したパス。
. 入力ファイルの拡張子を選択したモードの拡張子に替えたパス。例えば `-m pmd phrase.sxl` では `phrase.mml` になります。

PMD の `filename` メタデータは出力先の指定には使えません。ソースで設定する方法は xref:sxmml-reference-manual.adoc#ソースの既定出力先[ソースの既定出力先]を参照してください。

PMD 向けの MML は CP932 です。UTF-8 の端末では `iconv -f CP932 -t UTF-8 phrase.mml` で内容を読めます。
FM トラック A～F で `@0` を使う場合は、先に対応する音色を定義してください。音色の定義方法は xref:sxmml-reference-manual.adoc[MML 記述者向けリファレンス]を参照してください。
