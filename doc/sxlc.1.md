# 名前

sxlc — Scheme で記述した sxmml ソースを変換する

# 書式

    sxlc [-m mode] [-O level] [-o output] [-c command] [-w] [--] file
    sxlc -l | -h | -v

長い形式は `--mode`、`--optimize`、`--output`、`--command`、`--wsl`、`--list`、`--help`、`--version`。

# 説明

sxlc は *file* を Scheme ソースとして読み込み、トラックに登録された MML から生成物を作る。入力ファイルは一つだけ指定する。オプションは *file* より前に書き、*file* より後ろに引数があると使用法の誤りとなる。`-` で始まるファイル名は `--` の後に書く。現在の出力形式は PMD 向け MML と、実験的な PMD バイナリ。動作環境は Gauche 0.9.15。

ビルド・インストールの手順は [README](../README.md#最初の変換)を参照。入力には Scheme の式が含まれるため、信頼できるソースを指定する。

# オプション

**-m** *mode*, `--mode` *mode*
:   変換モードを選ぶ。PMD4 向けには `pmd`、PMD3 向けには `pmd3` を指定する。PMD のバイナリを直接生成する実験的なモードとして、PMD4 向けの `pmd-binary` と `pmd4-binary`、PMD3 向けの `pmd3-binary` がある。省略した場合はソース中の `(sxmml-mode pmd)` などが必要。CLI とソースの両方で指定すると、この指定が有効になり、ソース中の `sxmml-mode` は警告を表示して無視される。

**-O** *level*, `--optimize` *level*
:   整数の最適化水準。既定値は `1`。`0` 以下は通常の最適化なし、`1` は第 1 段階、`2` 以上は第 1・第 2 段階。コンパイル後のオブジェクト数を減らす処理であり、生成ファイルの文字列長を評価基準にはしない。通常の最適化を避けるには `-O 0` を指定する。品質上の制約は [issue #8](https://github.com/sayzbrdg/sxmml/issues/8)を参照。

**-o** *output*, `--output` *output*
:   生成物を *output* に書き込む。相対パスは現在のディレクトリを基準とする。省略した場合は *file* の拡張子を、選んだモードの拡張子（PMD 向けは `.mml`、PMD バイナリは `.m`）に替えたパスへ生成する。出力先が *file* と同じファイルになる場合は、ソースを上書きせず使用法の誤りとして終了値 2 で終了する。

**-c** *command*, `--command` *command*
:   生成後に *command* を起動し、出力名を後ろへ付ける。*command* の引用・エスケープは指定する側が行う。sxlc が追加する出力名は **-w** の有無にかかわらずエスケープし、空白入りの名前も一引数として渡す。**-w** を指定しない場合、後処理の標準出力と標準エラー出力は変換せずにそのまま出る。*command* の字句の誤り（閉じていない引用符など）は、変換の前に検出して使用法の誤りとする。後処理が 0 以外の終了値やシグナルで終了した場合や、起動できなかった場合は、標準エラー出力に通知して終了値 3 で終了する。変換は成功しているため生成物は残る。

**-w**, `--wsl`
:   **-c** と併用したとき、`wslpath -aw` で後処理へ渡す名前を Windows 形式のパスにし、後処理の標準出力と標準エラー出力を CP932 から変換して標準出力に表示する。WSL から Windows のツールを後処理に使うための指定である。CP932 として復号できないバイト列は置換文字に置き換える。`wslpath` が必要。`wslpath` が失敗した場合は終了値 3 で終了する。

**-l**, `--list`
:   現在の実行環境で見つかるバックエンドモジュールを表示して終了する。内容は環境によって変わる。

**-h**, `--help`
:   使用法を表示して終了する。

**-v**, `--version`
:   パッケージのバージョンを表示して終了する。

# 入力と出力

生成先は **-o** で指定する。省略した場合は *file* の拡張子を、選んだモードの拡張子（`.mml` または `.m`）に替えたパスへ生成する。生成後に表示する `Translate` 行の出力名と **-c** へ渡す名前は、実際の生成先と一致する。ソース中の `(define-metadata filename "出力先")` は生成先の指定には使われず、警告 `warning: metadata 'filename' is ignored; use the -o option of sxlc to set the output file` を表示して無視される。

**-c** で起動する後処理には、生成名を末尾の一引数として渡す。生成名はシェルの字句解析を通さないため、空白や `;` を含む名前もそのまま一引数になる。

PMD 向け生成物は CP932、改行は CRLF。生成後に出力名、モード、最適化水準を表示し、tick 数が正のトラックについて合計 tick 数を表示する。ループ位置を指定したトラックでは loop の tick 数も表示する。外部ドライバーでの演奏時間を示す値ではない。

PMD バイナリのモード（`pmd-binary`、`pmd4-binary`、`pmd3-binary`）は実験的な機能であり、外部コンパイラを使わずに PMD のバイナリを直接生成する。生成物が MC.EXE の出力と同じであることは保証しない（PMD 向け MML を MC.EXE でコンパイルした結果と一致するとは限らない）。同じ条件からはバイト単位で同じ生成物ができることと、失敗時の扱いは他のモードと同じ。

# 例

導入済みの `sxlc` が使えるシェルで次を実行する。

```console
printf '%s\n' '(mml G "c8r8")' > first.sxl
sxlc -m pmd first.sxl
iconv -f CP932 -t UTF-8 first.mml
```

最初の変換では `first.mml` が作られ、`Track G: total: 24` と表示される。

# 終了とエラー

**-h**、**-v**、**-l** は正常終了する。終了値は次のとおり。ソースが `exit` を呼んだ場合は、その値で終了する。

0
:   成功。**-c** を指定した場合は後処理も成功。

1
:   変換の失敗。ソースの読み込み・評価、MML、生成、出力先のエラー。

2
:   使用法の誤り。不正なオプションや引数、入力ファイル名なし、**-m** のモードを選べない、**-c** の字句の誤り、出力先が入力ファイルと同じ、*file* より後ろの引数。誤りの内容と使用法を表示する。

3
:   後処理の失敗。**-c** の後処理が 0 以外の終了値やシグナルで終了した、起動できなかった、**-w** の `wslpath` が失敗した。

モードが CLI とソースの双方で未指定ならエラーとなる。未登録トラック、不正な MML、未定義の FM 音色なども変換に失敗する。変換に失敗した場合は終了値 1 で終了し、出力先の既存ファイルを変更せず、途中までの生成物を残さない。診断と終了値は[外部動作仕様](behavior-spec.md#失敗条件と境界値)を参照。

既知の問題の対応状況と詳細は [既知の課題（GitHub の issue）](https://github.com/sayzbrdg/sxmml/issues)を参照。
