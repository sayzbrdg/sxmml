= `sxmml.command` の共通コマンド処理
:toc: left

トラック文脈（`<sxmml-mml-context>`）の参照・更新、音高・音長の計算、および IR オブジェクトの生成を行う共通処理層です。文字列解析、PEG、登録環境のパラメータ、トラック検索・登録には依存しません。

実装は link:../../sxmml/command.scm[command.scm] にあります。このモジュールは 18 手続きを定義し、16 手続きを公開します。`sxmml` モジュールがこのモジュールを `extend` します。

== 入力とエラーの契約

各手続きは、呼び出し側が用意した `<sxmml-mml-context>`（`ctx`）と解釈済みの値を受け取ります。

* オクターブ・移調量・音高・変化記号は整数、音名の半音番号（`pitch-class`）は 0～11、既定音長の分母は正の整数、付点数は 0 以上の整数、分解能は正の整数、音長 `ticks` は正の数値を前提とします。
* 音長計算の分母に `#f` を渡すと `ctx` の `default-length` を使います。
* 出力形式に固有の整数性や範囲制約は各バックエンドで検査します。
* 設定だけを更新する 4 手続きは `#f` を返し、NOP オブジェクトは生成しません。計算手続きは数値を返し、IR 生成手続きは新しいオブジェクトを返してトラックへの登録は行いません。

既知の規則違反（音長 0、分解能を超える付点、`L`・反復の使用規則違反、不正な反復回数）は `<sxmml-value-error>` を送出します。xref:mml.adoc[パーサー]経由では実行境界で同じ本文の `<sxmml-mml-syntax-error>` へ変換し、xref:processor.adoc[`mml-repeat`] 経由では `<sxmml-value-error>` にフォーム位置とトラック文脈を添えます。未知の Gauche 例外はそのまま送出します。

== 文脈の設定と計算

[[ref-command-default-length-set]]
=== `(sxmml-command-default-length-set! ctx denominator)`

`ctx` の `default-length` スロットを `denominator` に更新し、`#f` を返します。更新前に `%check-note-length` を呼び、`denominator` が `0` の場合は `<sxmml-value-error>`（`invalid note length: 0 (expected an integer >= 1)`）を送出します。

[[ref-command-octave-set]]
=== `(sxmml-command-octave-set! ctx octave)`

`ctx` の `current-octave` スロットを `octave` に更新し、`#f` を返します。

[[ref-command-octave-shift]]
=== `(sxmml-command-octave-shift! ctx delta)`

`ctx` の `current-octave` スロットへオクターブ単位の差分 `delta` を加算し、`#f` を返します。

[[ref-command-note-transpose-set]]
=== `(sxmml-command-note-transpose-set! ctx semitones)`

`K$` に相当する `ctx` の `current-transpose` スロットを半音単位の `semitones` に設定し、`#f` を返します。IR 命令として出力される `K`・`K*` とは別の解析時状態です。

[[ref-command-volume-up]]
=== `(sxmml-command-volume-up ctx)`

`ctx` の `volume-delta` スロットを参照し、その値を `value` に持つ `<sxmml-mml-volume-change>` を返します。`ctx` は変更しません。

[[ref-command-volume-down]]
=== `(sxmml-command-volume-down ctx)`

`ctx` の `volume-delta` スロットの符号を反転した値を `value` に持つ `<sxmml-mml-volume-change>` を返します。`ctx` は変更しません。

[[ref-command-note-pitch]]
=== `(sxmml-command-note-pitch ctx pitch-class accidental)`

`current-octave * 12 + pitch-class + accidental + current-transpose` を計算して返します。`ctx` は変更しません。

[[ref-command-note-length-to-ticks]]
=== `(sxmml-command-note-length\->ticks ctx resolution denominator dots)`

分解能 `resolution`、分母 `denominator`（`#f` のときは `ctx` の `default-length`）、付点数 `dots` から音長（tick 数）を計算して返します。`ctx` は変更しません。

基本音長を `resolution * 4 / length` で算出し、付点 1 つごとに直前の加算分を 2 で割って加えます。`length` が `0` の場合は `<sxmml-value-error>`（`invalid note length: 0 (expected an integer >= 1)`）、付点計算の途中で 2 で割り切れなくなった場合は `<sxmml-value-error>`（`number of dots exceeded resolution range`）を送出します。

== 音符・休符・リズムの IR 生成

この節の 4 手続きは、IR を生成する前に `%record-ticks!` を呼んで `current-ticks` の最内側ペアの累計と `ticks-statistics` の出現回数を更新します。統計は生成した IR の音長ごとに 1 回を数え、反復回数による乗算は行いません。

[[ref-command-note]]
=== `(sxmml-command-note! ctx pitch ticks)`

tick を記録し、`value` に `pitch`、`ticks` に `ticks` を持つ `<sxmml-mml-note>` を返します。

[[ref-command-rest]]
=== `(sxmml-command-rest! ctx ticks)`

tick を記録し、`value` が `#f`、`ticks` に `ticks` を持つ `<sxmml-mml-rest>` を返します。通常 MML とリズム MML の双方で使用します。

[[ref-command-portamento]]
=== `(sxmml-command-portamento! ctx start-pitch end-pitch ticks)`

tick を記録し、`value` に `(start-pitch . end-pitch)`、`ticks` に `ticks` を持つ `<sxmml-mml-portamento>` を返します。始点・終点の音高を確定する時点は呼び出し側が管理します。

[[ref-command-rhythm-on]]
=== `(sxmml-command-rhythm-on! ctx instruments ticks)`

tick を記録し、`value` が `#t`、`ticks` に `ticks` を持つ `<sxmml-rhythm-emit>` を返します。`instruments` には `bass`・`snare`・`tom`・`cymbal`・`hihat`・`rimshot` から選んだシンボルのリストを渡し、対応する楽器スロットを `#t` に設定します。

== 反復とループの IR 生成

[[ref-command-repeat-start]]
=== `(sxmml-command-repeat-start! ctx)`

`repeat-stack` へ `#f`、`current-ticks` へ新しい `(0 . 0)` を積み、`<sxmml-mml-repeat-start>` を返します。

[[ref-command-repeat-break]]
=== `(sxmml-command-repeat-break! ctx)`

反復脱出位置の tick を `current-ticks` 最内側ペアの `cdr` へ記録し、`repeat-stack` 先頭へ現在の `(default-length current-octave current-transpose)` を保存して `<sxmml-mml-repeat-break>` を返します。

次の順で検査し、違反時は `<sxmml-value-error>` を送出します。

* 反復の外で呼ばれた場合: `break command cannot be used outside of repeats`
* 同じ反復内で 2 回目以降に呼ばれた場合: `break command can be used only once in a repeat`

[[ref-command-repeat-end]]
=== `(sxmml-command-repeat-end! ctx count)`

反復を終了し、`value` に `count` を持つ `<sxmml-mml-repeat-end>` を返します。

次の順で検査し、違反時は `<sxmml-value-error>` を送出します。

* 対応する反復開始がない場合: `repeat end appeared before repeat start`
* `count` が正の正確な整数でない場合: `invalid repeat count: <値> (expected a positive exact integer)`

検査通過後、`repeat-stack` と `current-ticks` の先頭を取り出し、最終回の脱出区間を差し引いた tick 数を親の累計へ加算します。脱出があった場合は、保存しておいた `default-length`・`current-octave`・`current-transpose` を `ctx` へ復元します。

[[ref-command-loop]]
=== `(sxmml-command-loop! ctx)`

`loop-exists` を `#t` にし、`current-ticks` 先頭ペアの `cdr` へ現在の累計 tick を記録して `<sxmml-mml-loop>` を返します。

次の順で検査し、違反時は `<sxmml-value-error>` を送出します。

* 反復の内側で呼ばれた場合: `loop command cannot be used inside repeats`
* すでに同じトラックで `L` が使われている場合: `loop command can be used only once in a track`

== 非公開手続き

[[ref-command-record-ticks]]`(%record-ticks! ctx ticks)`::
`ctx` の `current-ticks` 最内側累計へ `ticks` を加算し、`ticks-statistics` の `ticks` キーの出現回数を 1 増やします。戻り値は規定しません。

[[ref-command-check-note-length]]`(%check-note-length denominator)`::
`denominator` が `0`（`eqv?`）の場合に `<sxmml-value-error>`（`invalid note length: 0 (expected an integer >= 1)`）を送出します。戻り値は規定しません。

== 音長計算例

分解能 48・分母 8・付点 1 の音長を計算する例です。

[source,scheme]
----
(use sxmml)
(sxmml-command-note-length->ticks (make <sxmml-mml-context>) 48 8 1)
;; => 36
----
