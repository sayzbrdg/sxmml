= `sxmml.backend.pmd-source` の生成処理
:toc: left

PMD向けMML出力の55定義（手続き54件・クラス1件）を持ちます。モード情報は読込み時に登録し、初期トラック設定は選択時に共通setup!で実行します。定義の規則と最適化選択は xref:pmd.adoc[PMD共通処理]を使います。

公開出力は出力環境一つを受け、出力結果を返します。A～J・Lに対応する出力トラックが必要です。出力中に現在の登録環境・モード・sxmml-source-fileを参照せず、入力を変更しません。作業用のトラック状態は明示引数、音色番号表・使用id表と定義参照は局所状態とクロージャで渡します。

出力先#fは`<sxmml-value-error>`、本文`output file is not specified`で報告し、入力名から補完しません。出力先と同じディレクトリの一時ファイルへCP932で書き、成功後に改名します。失敗時は既存出力を保持し、一時ファイルを破棄します。入力元source=#fならヘッダーのfromだけを省き、改行・モード行・PMD3終端は維持します。

本文全体を一つの文字列ポートへ出力し、FM音色指定の出力時に使用idを記録します。使用定義を番号順に書いた後で本文を出力し、使用音色収集のためのIR追加全件走査は行いません。最適化水準で音色省略の有無を分けません。
