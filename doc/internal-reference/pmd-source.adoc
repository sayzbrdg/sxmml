= `sxmml.backend.pmd-source` の生成処理
:toc: left

PMD 向けの MML ソース（`.mml`）を生成するバックエンドです。読み込み時にモード `pmd-source`（別名 `pmd`・`pmd4-source`）と `pmd3-source`（別名 `pmd3`）を登録し、モード選択時に `sxmml-pmd-setup!` で初期トラックを登録します。共通のトラック選択、定義検査、最適化選択は xref:pmd.adoc[`sxmml.backend.pmd`] を使います。

公開出力手続きは出力環境一つを受け取り、出力先と採用トラック名を持つ `<sxmml-output-result>` を返します。出力中に現在の登録環境・選択モード・`sxmml-source-file` を参照せず、入力環境と IR は変更しません。

出力先が `#f` の場合は `<sxmml-value-error>`（`output file is not specified`）になります。出力は出力先と同じディレクトリの一時ファイルへ CP932（改行 CRLF）で書き込み、完了後にリネームします。失敗時は既存の出力ファイルを変更せず、一時ファイルを破棄します。

本文全体を文字列ポートへ生成しながら使用した FM 音色に初出順で番号を割り当て、ヘッダー・メタデータ・PPZ8 拡張宣言・使用 FM 音色定義・トラック本文の順に出力します。通常トラックとリズムの K 行は最頻音長を tick 数で保持し、PMD4 向けは `l%N`、PMD3 向けは全音符の tick 数（分解能 × 4）を最頻音長で割った分母を `lN` として書きます（割り切れない場合は `<sxmml-value-error>`）。

数値・定義形式の違反は `<sxmml-value-error>`、未定義の音色・LFO・エンベロープは `<sxmml-reference-error>`、同一トラック内の重複 `L` は `<sxmml-mml-syntax-error>`、FM 音色の 257 種類目参照は `<sxmml-error>` になります。出力値の許容範囲の一覧は xref:../behavior-spec.adoc#pmd-source-の出力値の検査[外部動作仕様]を参照してください。

実装は link:../../sxmml/backend/pmd-source.scm[pmd-source.scm] にあります。このモジュールは 52 手続きと 1 クラスを定義し、3 手続きを公開します。

== 公開出力手続き

[[ref-pmd-source-sxmml-pmd-source-output]]
=== `(sxmml-pmd-source-output env)`

出力環境 `env` から PMD4 向け MML（`PMDver4.8`）を生成し、`<sxmml-output-result>` を返します。

[[ref-pmd-source-sxmml-pmd4-source-output]]
=== `(sxmml-pmd4-source-output env)`

`sxmml-pmd-source-output` と同じ PMD4 向けの公開出力手続きです。

[[ref-pmd-source-sxmml-pmd3-source-output]]
=== `(sxmml-pmd3-source-output env)`

出力環境 `env` から PMD3 向け MML（`PMDver3.3`）を生成し、`<sxmml-output-result>` を返します。メタデータ・PPZ8 拡張宣言をコメント行（``; ``）として出力し、既定音長を分母形式 `lN` で書き、ファイル末尾に `0x1a` を付けます。

== トラック状態クラス

[[ref-pmd-source-class-sxmml-pmd-track-environment]]
=== `<sxmml-pmd-track-environment>`

1 トラックの出力中に参照する状態と音源別コールバックを保持する非公開クラスです。`(make <sxmml-pmd-track-environment> [:octave 値] [:mode 値] ...)` で生成します。

* `octave`（`:octave`、初期値 `255`）: 直前に出力した音符・ポルタメントのオクターブ。出力中に更新します。
* `mode`（`:mode`、初期値 `0`）: トラックの既定音長（tick 数）。一致する音長は出力時に省略します。
* `voice-output`・`volume-output`・`volume-change-output`・`tempo-output`・`lfo-output`・`envelope-output`（同名キーワード、初期値 `#f`）: 通常トラック用の出力手続き。生成後は変更しません。リズム出力では使用しません。

== 出力全体とヘッダー・メタデータ・音色

[[ref-pmd-source-internal-pmd-source-output]]`(%pmd-source-output env pmd3?)`::
PMD4／PMD3 共通の生成処理です。出力先が `#f` なら `<sxmml-value-error>` を送出します。`sxmml-pmd-output-tracks-select` で存在する固定パートと非空の PPZ8 トラック（最大 8 本）を選び、`filename` メタデータの警告を確認してから一時ファイルへ書き出します。
+
文字列ポートへ全トラック本文を生成しながら `<sxmml-pmd-fm-voices>` に使用 FM 音色を集め、ヘッダー・メタデータ・`#PPZExtend`（PPZ8 使用時）・使用 FM 音色定義・本文（PMD3 は末尾 `0x1a`）の順に出力し、リネーム後に `<sxmml-output-result>` を返します。

[[ref-pmd-source-internal-pmd-source-head-output]]`(%pmd-source-head-output env pmd3?)`::
入力ファイル名とモード行を出力します。
1 行目に `;{empty}; This file was generated by sxmml`（`env` の `source` が `#f` でなければ `` from <basename>`` を付与）、2 行目に `;{empty}; mode: PMDver4.8` または `;{empty}; mode: PMDver3.3` を書きます。

[[ref-pmd-source-internal-pmd-source-meta-output]]`(%pmd-source-meta-output env pmd3?)`::
`title`・`composer`・`arranger`・`pcmfile`・`ppzfile`・`ppsfile`、曲単位設定（`#Detune`・`#EnvelopeSpeed`・`#LFOSpeed` の `Normal`／`Extend`）、`memo` の順にメタデータを出力します。値の検査は `sxmml-pmd-metadata-value` と `sxmml-pmd-extended-settings` を使います。`pmd3?` が真のときは各行頭に ``; `` を付けます。

[[ref-pmd-source-internal-pmd-source-voice-output]]`(%pmd-source-voice-output voices)`::
`sxmml-pmd-for-each-fm-voice` を使い、使用された FM 音色だけを番号順に `@000 AL FB` と 4 オペレータ分（AR・DR・SR・RR・SL・TL・KS・ML・DT・AMS の 10 項目）の書式で出力します。各項目を許容範囲の正確な整数か検査し、DT2・SEG は出力しません。

== トラックと IR の走査

[[ref-pmd-source-internal-track-output]]`(%track-output env track lis part length-output voice-proc! vol-set-proc! vol-change-proc!)`::
最適化済みの通常トラック列 `lis` を出力します。`lis` が空なら何も出力しません。最頻音長を取得して `<sxmml-pmd-track-environment>` を作り、`part` と既定音長（最頻音長がある場合）を書いた後、`%pmd-track-output!` で IR 列を出力します。

[[ref-pmd-source-internal-fm-track-output]]`(%fm-track-output env track lis part length-output voice-proc)`::
FM パート用の出力手続きです。`voice-proc` と FM 用音量手続きを渡して `%track-output` を呼びます。

[[ref-pmd-source-internal-ssg-track-output]]`(%ssg-track-output env track lis part length-output)`::
SSG パート用の出力手続きです。SSG 用音色・音量手続きを渡して `%track-output` を呼びます。

[[ref-pmd-source-internal-pcm-track-output]]`(%pcm-track-output env track lis part length-output source)`::
PCM（`pcm`）および PPZ8（`ppz8`）パート用の出力手続きです。`source` に応じた PCM 音色解決クロージャと PCM 用音量手続きを渡して `%track-output` を呼びます。

[[ref-pmd-source-internal-pmd-track-output-bang]]`(%pmd-track-output! state lis)`::
平坦な IR 列 `lis` を先頭から順に `%pmd-ir-output!` へ渡し、ループ出現状態 `loop-seen?` と反復深さ `depth` を引き継ぎながら出力します。音符・ポルタメント出力により `state` の `octave` が更新されます。

[[ref-pmd-source-internal-pmd-ir-output-bang]]`(%pmd-ir-output! state obj loop-seen? depth)`::
IR 1 個のクラスに応じて対応する出力手続きを呼び、更新後の `loop-seen?` と `depth` を二値で返します。反復開始では深さ 1～32 を検査し、2 個目の `L` は `<sxmml-mml-syntax-error>` を送出します。未対応の IR は何も出力せず状態をそのまま返します。

[[ref-pmd-source-internal-pmd-rhythm-track-output]]`(%pmd-rhythm-track-output track lis length-output)`::
リズムトラック `L` の出力手続きです。`L` 命令の有無を調べ、局所状態を作って `%pmd-rhythm-definition-track-output` と `%pmd-rhythm-deploy-track-output!` を順に呼びます。

[[ref-pmd-source-internal-pmd-rhythm-definition-track-output]]`(%pmd-rhythm-definition-track-output state has-loop? lis)`::
リズム定義トラック `R0`（ループがある場合は `L` の後ろを `R1`）を出力します。`lis` が空なら何も出力しません。反復深さ（1～32）と重複 `L`（`<sxmml-mml-syntax-error>`）を検査し、`R1` は反復深さ 0・`loop-seen? #t` で開始します。

[[ref-pmd-source-internal-pmd-rhythm-deploy-track-output]]`(%pmd-rhythm-deploy-track-output! state track has-loop? lis length-output)`::
リズム展開トラック `K` を出力します。`lis` が空なら何も出力しません。最頻音長があれば `state` の `mode` へ設定して `length-output` で書き、`R0`（`has-loop?` が真なら続けて `` L R1``）を出力します。

== 値検査と通常命令の出力

[[ref-pmd-source-internal-pmd-value-check]]`(%pmd-value-check kind value min max)`::
`value` が `min` 以上 `max` 以下の正確な整数であればそのまま返し、違反すれば `<sxmml-value-error>`（`invalid <kind>: <value> (expected an integer from <min> to <max>)`）を送出します。

[[ref-pmd-source-internal-pmd-note-check]]`(%pmd-note-check note :optional (kind "note"))`::
音高 `note` が 12～107（`o1c`～`o8b`）の正確な整数かを検査して返します。非整数は `%pmd-value-check` のエラー、範囲外は音名と `o1c - o8b` を示す `<sxmml-value-error>` になります。`kind` で通常音符・ポルタメント始点・終点を区別します。

[[ref-pmd-source-internal-pmd-voice-number]]`(%pmd-voice-number obj max kind)`::
音色 IR の `value`（シンボル）を数値へ変換し、0～`max` の正確な整数かを検査して返します。違反時は `invalid <kind>: <value> (expected an integer from 0 to <max>)` の `<sxmml-value-error>` になります。現在は SSG 音色（`max` 9）から呼び出されます。

[[ref-pmd-source-internal-pmd-rest-output]]`(%pmd-rest-output state obj)`::
休符を `r` または `r%N` で出力します。255 tick を超える長さは `r%255` を繰り返して分割し、既定音長（`state` の `mode`）と一致する部分は数値を省略します。

[[ref-pmd-source-internal-pmd-note-output]]`(%pmd-note-output! state obj)`::
音高を検査し、`state` の `octave` との差に応じて `oN`・`>`・`<` を付けて音名と音長を出力し、`octave` を更新します。255 tick を超える長さは `%255&` で分割し、既定音長と一致する部分は音長を省略します。

[[ref-pmd-source-internal-pmd-portamento-output]]`(%pmd-portamento-output! state obj)`::
始点音（`portamento start note`）、終点音（`portamento end note`）、音長（1～255 tick）を検査し、必要に応じてオクターブ指定を出力しつつ `{始点音終点音}%N` 形式で書き、`state` の `octave` を更新します。

[[ref-pmd-source-internal-pmd-tie-output]]`(%pmd-tie-output obj)`::
タイ記号 `&` を出力します。

[[ref-pmd-source-internal-pmd-gate-time-output]]`(%pmd-gate-time-output obj)`::
ゲートタイムを `qN`（0～255）で出力します。

[[ref-pmd-source-internal-pmd-fm-volume-output]]`(%pmd-fm-volume-output obj)`::
FM 音量を `VN`（0～127）で出力します。

[[ref-pmd-source-internal-pmd-ssg-volume-output]]`(%pmd-ssg-volume-output obj)`::
SSG 音量を `vN`（0～15）で出力します。

[[ref-pmd-source-internal-pmd-pcm-volume-output]]`(%pmd-pcm-volume-output obj)`::
PCM 音量を `VN`（0～255）で出力します。

[[ref-pmd-source-internal-pmd-fm-volume-change-output]]`(%pmd-fm-volume-change-output obj)`::
FM 相対音量（−255～255）を出力します。`+4` は `)`、`−4` は `(`、その他の 0 以上は `)%N`、負数は `(%N` です。

[[ref-pmd-source-internal-pmd-ssg-volume-change-output]]`(%pmd-ssg-volume-change-output obj)`::
SSG 相対音量（−255～255）を出力します。`+1` は `)`、`−1` は `(`、その他は `)%N`・`(%N` です。

[[ref-pmd-source-internal-pmd-pcm-volume-change-output]]`(%pmd-pcm-volume-change-output obj)`::
PCM 相対音量（−255～255）を出力します。`+16` は `)`、`−16` は `(`、その他は `)%N`・`(%N` です。

[[ref-pmd-source-internal-pmd-tempo-absolute-output]]`(%pmd-tempo-absolute-output obj)`::
Timer-B 絶対値を `TN`（0～255）で出力します。

[[ref-pmd-source-internal-pmd-tempo-output]]`(%pmd-tempo-output env obj)`::
`sxmml-bpm\->timer-b` に `env` の `resolution` を渡して BPM を Timer-B 値へ換算し、`TN` で出力します。

[[ref-pmd-source-internal-pmd-detune-output]]`(%pmd-detune-output obj)`::
デチューンを `DN`（−32768～32767）で出力します。

[[ref-pmd-source-internal-pmd-transpose-output]]`(%pmd-transpose-output obj)`::
絶対移調を `_N`（−128～127）で出力します。

[[ref-pmd-source-internal-pmd-transpose-change-output]]`(%pmd-transpose-change-output obj)`::
相対移調を `__N`（−128～127）で出力します。

[[ref-pmd-source-internal-pmd-pan-output]]`(%pmd-pan-output obj)`::
パンを `pN`（0～3）で出力します。

[[ref-pmd-source-internal-pmd-lfo-output]]`(%pmd-lfo-output env obj)`::
`env` の `lfo` 表から定義を引き、`sxmml-pmd-lfo-values` で検査して出力します。`default`・`triangle` は `Md1,d2,d3,d4`（チャンネル `B` は `MB...`）、`evolution` は `MDd1,d2` または `MDd1,d2,d3`（チャンネル `B` は `MDB...`、1 値定義も 2 値で出力、値 3 の `0` も省略しない）です。未定義は `<sxmml-reference-error>`、チャンネルが `#f`・`A`・`B` 以外は `<sxmml-value-error>` です。`%pmd-ir-output!` は `<sxmml-mml-lfo>` と `<sxmml-pmd-lfo-evolution>` の双方をこの手続きへ渡します。

[[ref-pmd-source-internal-pmd-lfo-switch-output]]`(%pmd-lfo-switch-output obj)`::
LFO スイッチを `*1`／`*0`（チャンネル `B` は `*B1`／`*B0`）で出力します。チャンネルが `#f`・`A`・`B` 以外は `<sxmml-value-error>` です。

[[ref-pmd-source-internal-pmd-envelope-output]]`(%pmd-envelope-output env obj)`::
`env` の `envelope` 表から定義を引き、`sxmml-pmd-envelope-values` で検査して `E` とカンマ区切りの 4・5・6 値を出力します。未定義は `<sxmml-reference-error>` です。

[[ref-pmd-source-internal-pmd-ssg-voice-output]]`(%pmd-ssg-voice-output obj)`::
`%pmd-voice-number` で 0～9 の整数に検査し、`@N` で出力します。

[[ref-pmd-source-internal-pmd-pcm-voice-output]]`(%pmd-pcm-voice-output env obj source)`::
`sxmml-pmd-pcm-voice-number` で解決した番号を `@N` で出力します。

[[ref-pmd-source-internal-pmd-noise-freq-output]]`(%pmd-noise-freq-output obj)`::
ノイズ周波数を `wN`（0～31）で出力します。

[[ref-pmd-source-internal-pmd-output-switch-output]]`(%pmd-output-switch-output obj)`::
出力切替を `PN`（1～3）で出力します。

[[ref-pmd-source-internal-pmd-repeat-start-output]]`(%pmd-repeat-start-output obj)`::
反復開始 `[` を出力します。

[[ref-pmd-source-internal-pmd-repeat-end-output]]`(%pmd-repeat-end-output obj)`::
反復終了と回数 `]N`（1～255）を出力します。

[[ref-pmd-source-internal-pmd-repeat-break-output]]`(%pmd-repeat-break-output obj)`::
反復脱出 `:` を出力します。

[[ref-pmd-source-internal-pmd-loop-output]]`(%pmd-loop-output obj)`::
ループ位置 `L` を出力します。

== リズム命令の出力と補助

[[ref-pmd-source-internal-pmd-rhythm-emit-output]]`(%pmd-rhythm-emit-output state obj)`::
選択された各楽器について、発音（`value` が真）なら `\b`・`\s`・`\t`・`\c`・`\h`・`\i`、停止（偽）なら `\bp`～`\ip` を出力します。発音時は続けて `ticks` 分の休符を `%pmd-rest-output` で出力します。

[[ref-pmd-source-internal-pmd-rhythm-volume-output]]`(%pmd-rhythm-volume-output obj)`::
設定済みのスロットについて、全体音量を `\VN`（0～63）、楽器別音量を `\vbN`～`\viN`（各 0～31）で出力します。

[[ref-pmd-source-internal-pmd-rhythm-volume-change-output]]`(%pmd-rhythm-volume-change-output obj)`::
設定済みのスロットについて、楽器別の相対音量を符号付きで `\vb+N`／`\vb-N` 等（各 −31～31）で出力します。

[[ref-pmd-source-internal-pmd-rhythm-pan-output]]`(%pmd-rhythm-pan-output obj)`::
設定済みのスロットについて、楽器別パンを `1`→`r`、`2`→`l`、`3`→`m` に対応付けて `\rb` 等で出力します。`1`～`3`・`#f` 以外は `<sxmml-value-error>`（`invalid rhythm pan`）です。

[[ref-pmd-source-internal-note-number-to-pmd-note]]`(%note-number\->pmd-note note)`::
半音番号 `note` を `floor/` で 12 分割し、`(オクターブ . 音名文字列)` の対（音名は `c`・`c+`・`d`・`e-`・`e`・`f`・`f+`・`g`・`a-`・`a`・`b-`・`b`）を返します。負の音高も 0～11 の音名に正規化します。
