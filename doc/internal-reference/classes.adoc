= `sxmml.classes` のクラス
:toc: left

`sxmml.classes` は 42 クラスと、2 つのエラーの種類を定義し、`export-all` で公開します。slot の初期化は Gauche 0.9.15 の `define-class`、`:init-keyword`、`:init-value`、`:init-form` に従います。MML の記法は xref:../sxmml-mml-manual.adoc[MML コマンドマニュアル]を参照してください。

各行の「固有 slot」は親クラスから継承する slot を省きます。作成書式は `(make クラス [:初期化キーワード 値] ...)` で、結果はそのクラスのインスタンスです。`make` は新しいオブジェクトを作り、既存の sxmml 環境は変更しません。slot は `slot-ref` で参照し、処理中に `slot-set!` 等で更新されます。初期値の書かれていない slot には、この定義で既定値を与えていません。初期化キーワードのない slot を `make` の引数で設定することはできません。不正な初期化引数や未定義 slot へのアクセスは Gauche のオブジェクト操作で失敗します。数値や文字列の業務上の妥当性は、クラス定義では検査しません。

== リズムオブジェクト

`<sxmml-rhythm>` 系は、楽器ごとの `bass`、`snare`、`tom`、`cymbal`、`hihat`、`rimshot` を `:楽器名` で初期化できます。基底クラスでの各既定値は `#f` です。`<sxmml-rhythm-emit>` は多重継承により音符の `ticks` も持ちます。オブジェクト生成のみでは演奏時間や出力を更新せず、解析器と生成器が slot を参照します。

|[[ref-classes-class-sxmml-rhythm-emit]]`<sxmml-rhythm-emit>` |`<sxmml-rhythm>`、`<sxmml-mml-note>` |発音または停止を表すイベント |追加なし |link:../../sxmml/classes.scm[classes.scm]

== 登録する設定値と音色

次の三つの基底クラスでは、`id`、`type`、`value` のうち表に示す slot に初期化キーワードがありますが、既定値は定義されていません。利用する処理が必要とする値を指定してください。`<sxmml-opmn-voice>` は OPM と OPN に共通する音色型で、バックエンドが全 slot を生成物に使用することを意味しません。

== エラーの種類

sxmml のエラーの種類は `define-condition-type` で定義した condition type です。`<sxmml-form-error>` は `sxmml.form` が作り、`sxlc` は種類の名前で始まる `*** SXMML-FORM-ERROR: …` を表示します。ほかのエラーは、まだふつうの `<error>` で投げます（https://github.com/sayzbrdg/sxmml/issues/80[issue #80]）。

[cols="2,1,3,4,1",options="header"]
|===
|種類 |親 |役割 |slot と取り出し |ソース
|[[ref-classes-class-sxmml-error]]`<sxmml-error>` |`<error>` |sxmml のエラーの基底 |なし。[[ref-classes-sxmml-error-p]]述語 `sxmml-error?` |link:../../sxmml/classes.scm[classes.scm]
|[[ref-classes-class-sxmml-form-error]]`<sxmml-form-error>` |`<sxmml-error>` |定義のフォームの誤り |`location`（`"ファイル:行"` か `#f`）を [[ref-classes-sxmml-form-error-location]]`sxmml-form-error-location` で、`cause`（元のエラーか `#f`）を [[ref-classes-sxmml-form-error-cause]]`sxmml-form-error-cause` で取り出す。[[ref-classes-sxmml-form-error-p]]述語 `sxmml-form-error?` |link:../../sxmml/classes.scm[classes.scm]
|===

`load` の途中で起きたエラーは、Gauche が読み込みの文脈を付けた compound condition にして投げ直します。述語と取り出しは、その compound condition にも使えます。

== クラスの作成例

リポジトリのルートで Gauche 0.9.15 を使用します。

[source,console]
----
$ gosh -I. -e '(use sxmml.classes) (write (slot-ref (make <sxmml-mml-context>) (quote default-length))) (newline)'
4
----
