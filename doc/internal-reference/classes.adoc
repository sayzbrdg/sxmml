= `sxmml.classes` のクラスとエラー型
:toc: left

環境・出力準備・最適化状態・MML オブジェクト・リズムオブジェクト・設定定義・エラーおよび文脈のコンディション型を定義するモジュールです。

実装は link:../../sxmml/classes.scm[classes.scm] にあります。このモジュールは通常クラス 46 件とコンディション型 8 件（計 54 クラス）、およびコンディション用の述語 8 件・アクセサ 2 件（計 10 手続き）の合計 64 定義を持ち、`export-all` ですべて公開します。

スロットの初期化は Gauche 0.9.15 の `define-class`、`:init-keyword`、`:init-value`、`:init-form` に従います。MML 文字列の記法は xref:../sxmml-mml-manual.adoc[MML コマンドマニュアル]を参照してください。

== 共通の仕様

クラスのインスタンス作成書式は `(make クラス [:初期化キーワード 値] ...)` です。`make` は新しいオブジェクトを生成し、既存の sxmml 環境を変更しません。スロットは `slot-ref` で参照し、処理中に `slot-set!` などで更新します。

* 初期値の記載がないスロットには定義上の既定値を与えません。
* 初期化キーワードの記載がないスロットは `make` の引数で指定できません。
* `:init-form` で生成するハッシュ表や木はインスタンス作成ごとに新しく作られるため、別インスタンスと共有しません。
* 不正な初期化引数や未定義スロットへのアクセスは Gauche のオブジェクト操作エラーになります。業務上の値の範囲や妥当性はクラス定義では検査しません。

== 環境と最適化状態のクラス

[[ref-classes-class-sxmml-mode]]
=== `<sxmml-mode>`

バックエンドモードの登録情報を保持するクラスです（親クラスなし）。生成しただけでは共有表への登録や初期設定は行わず、型と名前衝突の検査は `sxmml-mode-register!` で行います。

* `name`（`:name`, 初期値 `#f`）: モードの正式名シンボル（登録時に必須）。
* `aliases`（`:aliases`, 初期値 `()`）: 別名シンボルのリスト。
* `setup`（`:setup`, 初期値 `#f`）: モード選択時に引数なしで呼ぶ手続き、または `#f`。
* `backend`（`:backend`, 初期値 `#f`）: `<sxmml-output-environment>` を受けて `<sxmml-output-result>` を返す手続き（登録時に必須）。
* `output-extension`（`:output-extension`, 初期値 `#f`）: 既定の出力拡張子文字列、または `#f`。

[[ref-classes-class-sxmml-environment]]
=== `<sxmml-environment>`

楽曲コンパイル全体の設定と登録表を保持するクラスです（親クラスなし）。

* `resolution`（`:resolution`, 初期値 `24`）: 四分音符あたりの tick 数。
* `options`（初期化キーワードなし, `eq-comparator` の新しい空ハッシュ表）: 利用者定義の設定表。
* `default-output-path`（初期化キーワードなし, 初期値 `#f`）: ソースで指定した既定出力先。最終的な出力先決定は `sxlc` が行います。
* `metadata`・`lfo`・`envelope`・`voice`・`track`（いずれも初期化キーワードなし, `eq-comparator` の新しい空ハッシュ表）: 各種定義とトラックの登録表。`voice` は種類シンボルをキー、名前別の定義表を値とするハッシュ表です。
* `mode`（`:mode`, 初期値 `#f`）: 現在選択中の `<sxmml-mode>`。

[[ref-classes-class-sxmml-output-environment]]
=== `<sxmml-output-environment>`

各バックエンドへ渡す出力用の定義表・設定・トラック表を保持するクラスです（親クラスなし）。全スロットが同名の初期化キーワードを持ちます。xref:output.adoc#ref-output-make-sxmml-output-environment[`make-sxmml-output-environment`] 経由で作成する場合は `:output` と `:optimize` が必須です。

* `resolution`（`:resolution`, 初期値 `24`）
* `metadata`・`voice`・`envelope`・`lfo`・`track`（各同名の初期化キーワード, `eq-comparator` の新しい空ハッシュ表）
* `jobs`（`:jobs`, 初期値 `1`）
* `optimize`（`:optimize`, 初期値 `0`）
* `output`（`:output`, 初期値 `#f`）
* `source`（`:source`, 初期値 `#f`）

[[ref-classes-class-sxmml-output-track]]
=== `<sxmml-output-track>`

平坦化済みの IR と確定した音長集計を保持する出力トラックのクラスです（親クラスなし）。全スロットが同名の初期化キーワードを持ちます。

* `name`（`:name`, 初期値 `#f`）: トラック名シンボル。
* `part`（`:part`, 初期値 `#f`）: 明示指定されたパート、または `#f`。
* `sound-source`（`:sound-source`, 初期値 `#f`）: 音源種別のシンボル、または未指定の `#f`。
* `ir`（`:ir`, 初期値 `()`）: 平坦化済みの IR リスト。
* `total-ticks`（`:total-ticks`, 初期値 `0`）: トラック全体の総 tick 数。
* `loop-ticks`（`:loop-ticks`, 初期値 `0`）: ループ区間の tick 数。
* `loop-exists`（`:loop-exists`, 初期値 `#f`）: `L` コマンドの有無。
* `ticks-statistics`（`:ticks-statistics`, `eqv-comparator` の新しい空ハッシュ表）: 音長ごとの出現回数表。

[[ref-classes-class-sxmml-output-result]]
=== `<sxmml-output-result>`

バックエンドが出力した結果を保持するクラスです（親クラスなし）。

* `output`（`:output`, 初期値 `#f`）: 実際の出力先。
* `track-names`（`:track-names`, 初期値 `()`）: 出力に採用した sxmml トラック名のリスト。

[[ref-classes-class-sxmml-optimize-environment]]
=== `<sxmml-optimize-environment>`

最適化の第 1 パスで音符間の設定命令を記録するクラスです（親クラスなし、初期化キーワードなし）。

* `inter-objects`（`equal-comparator` の新しい空ハッシュ表）: 鍵は命令クラス（LFO の設定・切替はクラスとチャンネルの対）。
* `objects-order`（`integer-comparator` の新しい空 tree map）: 出現順を保持するマップ。

[[ref-classes-class-sxmml-optimize-2nd-pass-context]]
=== `<sxmml-optimize-2nd-pass-context>`

最適化の第 2 パスで既出の設定値と反復深度を追跡するクラスです（親クラスなし、初期化キーワードなし）。

* `voice`・`volume`・`gate-time`・`pan`・`detune`・`envelope` および各 `*-placed`（初期値 `#f`）: 現在値と配置済みフラグ。
* `lfo`・`lfo-switch`（初期値 `()`）: チャンネルから値への連想リスト。
* `lfo-placed-channels`・`lfo-switch-placed-channels`（初期値 `()`）: 値を配置したチャンネルのリスト。
* `repeat-depth`（初期値 `0`）: 現在の反復ネスト深度。

[[ref-classes-class-sxmml-mml-context]]
=== `<sxmml-mml-context>`

トラック単位の解析状態と蓄積済み IR を保持するクラスです（親クラスなし）。

* `track`（`:track`, 初期値 `#f`）: トラック名シンボル。
* `part`（`:part`, 初期値 `#f`）: 割り当てパート、または `#f`。
* `sound-source`（`:sound-source`, 初期値 `#f`）: 音源種別のシンボル、または未指定の `#f`。
* `default-length`（`:default-length`, 初期値 `4`）: 既定音長の分母。
* `volume-delta`（`:volume-delta`, 初期値 `1`）: 相対音量コマンド `)` / `(` の変化幅。
* `current-octave`（`:current-octave`, 初期値 `4`）: 現在のオクターブ。
* `current-transpose`（`:current-transpose`, 初期値 `0`）: `K$` による現在のノート移調量（半音単位）。
* `current-ticks`（初期化キーワードなし, `:init-form (acons 0 0 ())`）: `(累計 tick . ループ／脱出位置 tick)` のスタック。
* `loop-exists`（`:loop-exists`, 初期値 `#f`）: `L` コマンド出現済みフラグ。
* `compiled-data`（初期化キーワードなし, 初期値 `()`）: 登録済み IR の cons 木。
* `repeat-stack`（初期化キーワードなし, 初期値 `()`）: 反復ネストごとの脱出復元状態スタック。
* `ticks-statistics`（初期化キーワードなし, `eqv-comparator` の新しい空ハッシュ表）: 音長ごとの出現回数表。

[[ref-classes-class-sxmml-rhythm-volume]]`<sxmml-rhythm-volume>`::
親: `<sxmml-rhythm>`。リズム音量指定。

[[ref-classes-class-sxmml-rhythm-volume-change]]`<sxmml-rhythm-volume-change>`::

親なし。音色定義の基底クラス（音色番号はバックエンドが決定するため保持しません）。固有スロット: `id`（`:id`）、`value`（`:value`）。

== エラーと文脈のコンディション型

既知の入力エラーは `define-condition-type` で定義したコンディション型で通知します。ソース位置とトラック名は独立したミキシンコンディションとして複合コンディションに合成し、エラー本文へは埋め込みません。

型判定には各コンディション型の述語または `condition-has-type?` を使います（`load` が付加する情報を含む複合コンディションにも対応するため、`is-a?` だけでは判定しません）。Gauche 由来の未知の例外や内部 IR・最適化の不整合は `<sxmml-error>` へ変換しません。

== クラスの作成例

リポジトリのルートで Gauche 0.9.15 を使用して `<sxmml-mml-context>` の既定値を確認する例です。

[source,console]
----
$ gosh -I. -e '(use sxmml.classes) (write (slot-ref (make <sxmml-mml-context>) (quote default-length))) (newline)' -E exit
4
----
