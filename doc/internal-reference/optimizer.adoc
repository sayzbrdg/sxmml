= `sxmml.optimizer` のIR列最適化
:toc: left

58手続きとrecord型3件を定義し、7手続きを公開します。入力は整列済みの有効な共通IR列、出力も平坦なIR列です。登録環境の検索、整列化、集計確定、最適化要求の数値解釈は行いません。

各処理は単独で使え、前の最適化処理の実行を前提にしません。他の処理の削減能力を包含する必要もありません。入力のリスト構造・IRを変更せず、変更するIRを新しく作り、未変更部分は共有できます。局所処理で自分が生成した設定IRの組立てに更新を使うこととは区別します。

反復圧縮には xref:repeat-tree.adoc[repeat-tree]を使い、回数2～255、制御費用は[ ]が2、[ : ]が3、窓幅は通常256・展開付き1024、展開上限256、入れ子上限32を維持します。探索の上限と出力形式の上限を同一の規則にはまとめません。削減効果はIRの要素数で評価し、意味保持とは区別します。


具体的なIRクラスの派生には、対応する既知の命令の最適化規則を適用します。既知の特殊化は親より先に判定し、LFOの選択と切替を別状態とします。親の規則を適用できない独自の意味を持つIRは、共通基底から定義します。型への所属は`is-a?`、複合した型制約は`of-type?`、実際のクラス同士の比較は`equal?`で表します。

結果のインスタンス同一性や、入力から独立した完全な複製は保証しません。再生成では原型のクラス、変更対象以外のインスタンススロットの値・未束縛状態を保持します。値自体は浅く共有します。絶対指定の上書きは後続IR、相対合成は先行の寄与元、リズム設定のまとめ直しは最初の残存効果の寄与元、休符結合は後の休符を原型とします。削除されたIRや、合成の原型に選ばれなかったIRの付加情報は保存しません。一律の未変更判定による再利用は行いません。

`%setting-effects->ir`・`%repeat-flatten`・`%repeat-expansion`・`%repeat-tree->ir`はtailの前へ構築します。tailは必須で、空リストなら単独の結果列になります。入力列・IR・tailを変更せず、自分が構築したセルだけを更新できます。反復の各出現のセルは別に作ります。

反復圧縮は、論理要素・出力テンプレート・出力IR数の三つのベクタを保持します。逆順原子列を一度走査して埋め、タイの先頭側を繰り返しコピーしません。圧縮結果の深さは一度求め、深さ上限の比較が必要な場合にだけrawを構築します。

== 利用例

[source,scheme]
----
(use sxmml)
(define-track G)
(mml G "r8r8")
(define ir (sxmml-ir-flatten (slot-ref (sxmml-track-get 'G) 'compiled-data)))
(print (length ir))                         ; 2
(print (length (sxmml-ir-merge-rests ir)))    ; 1
(print (length ir))                         ; 2
----

最適化前の整列化は xref:output.adoc[出力準備]、PMDの数値要求との対応は xref:pmd.adoc[PMD共通処理]へ分離しました。旧sxmml-optimize-treeは廃止しました。意味保持の確認範囲は link:../verification.md#q-01-音楽的な意味の保持[検証方針]を参照してください。
