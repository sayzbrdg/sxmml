= `sxmml.form` の定義の誤りの位置
:toc: left

`sxmml.form` には四つの定義があり、定義のマクロの誤りを、ソースの位置付きで知らせる三つの手続きを公開します。`sxmml` はこのモジュールを `extend` しません。`sxmml.voice` の `define-opn-voice` が使います。エラーの種類は xref:classes.adoc#ref-classes-class-sxmml-form-error[`<sxmml-form-error>`] を参照してください。`debug-source-info` と condition は Gauche 0.9.15 の動作に従います。

位置は `"ファイル:行"` の文字列で、フォームの開始行を示します。Gauche の `While loading … at line N` は、フォームを読み終えた行や、`begin` の行・終わりを示すので、`begin` の中や手続きの本体の定義の位置を示せません。メッセージは、位置があれば `ファイル:行: 本文`、なければ本文だけです。

[cols="2,4,4,1",options="header"]
|===
|名前・書式 |引数と役割 |戻り値・副作用・失敗条件 |ソース
|[[ref-form-sxmml-form-location]]`(sxmml-form-location form)` |マクロが受け取ったフォームの位置を作る |`(debug-source-info form)` が `(ファイル 行 …)` なら `"ファイル:行"`、それ以外（組み立てたフォームの `eval` など）は `#f` |link:../../sxmml/form.scm[form.scm]
|[[ref-form-sxmml-form-error]]`(sxmml-form-error form fmt arg ...)` |展開時の形の誤りを投げる |`format` で本文を作り、`location` を `form` の位置、`cause` を `#f` とした `<sxmml-form-error>` を投げる。戻らない |link:../../sxmml/form.scm[form.scm]
|[[ref-form-sxmml-form-call]]`(sxmml-form-call location thunk)` |実行時のエラーに位置を付ける |`thunk` の値を返す。中で起きたメッセージを持つ condition は、`location`、元のエラーを `cause` とした `<sxmml-form-error>` として投げ直す。中で起きたのがすでに `<sxmml-form-error>` なら、いちばん内側の位置を残すためにそのまま通す。メッセージを持たない値の `raise` もそのまま通す。`location` が `#f` なら、何もせずに `thunk` を呼ぶ |link:../../sxmml/form.scm[form.scm]
|[[ref-form-internal-located-message]]`(%located-message location message)` |メッセージに位置を付ける |`location` があれば `"位置: 本文"`、`#f` なら `message` をそのまま返す。`sxmml-form-error` と `sxmml-form-call` が使う |link:../../sxmml/form.scm[form.scm]
|===

== 使用例

`define-opn-voice` は、展開時に `sxmml-form-location` で位置を取り、登録の呼び出しを `sxmml-form-call` で包みます。

[source,console]
----
$ gosh -I. -e '(use sxmml.form)' -e '(guard (e [else (print (condition-message e))]) (sxmml-form-call "./song.sxl:3" (lambda () (error "boom"))))'
./song.sxl:3: boom
----
