= `sxmml.mml` の手続きとパーサー
:toc: left

通常 MML とリズム MML の文字列を解析し、sxmml IR オブジェクト列へ変換する PEG パーサー群を定義するモジュールです。

実装は link:../../sxmml/mml.scm[mml.scm] にあります。このモジュールは 77 定義（手続き 76 件・マクロ 1 件）を持ち、`make-sxmml-mml-parser` と `make-sxmml-rhythm-parser` の 2 手続きを公開します。命令表のハッシュ表（`+*note-command*+`・`+*rhythm-command*+`）は呼び出せないため索引の掲載対象外です。

`define-inline`、パラメータ、`parser.peg` の動作は Gauche 0.9.15 に従います。MML 文字列の記法は xref:../sxmml-mml-manual.adoc[MML コマンドマニュアル]を参照してください。

== 構造とエラー境界

文脈の更新、音高・音長の計算、IR の生成と tick 集計は xref:command.adoc[`sxmml.command`] へ委ね、このモジュールは PEG による字句・構文解析と失敗情報の生成を担当します。音長計算の例は xref:command.adoc#_音長計算例[共通層の例]を参照してください。

`$` で始まる項目の大半は `parser.peg` のパーサー値（入力状態を受ける手続き）です。通常は直接呼ばず、公開手続き `make-sxmml-mml-parser` または `make-sxmml-rhythm-parser` が返すトップレベルパーサー経由で使用します。パーサーの構築やオブジェクト生成だけでは登録済みトラックは変更しません。

命令文字に対応するパーサーは命令表（`+*note-command*+` または `+*rhythm-command*+`）から選択します。未登録の文字に出会った場合は `$raise` へ `unknown MML command: "<文字>"` を渡し、回復不能な PEG の失敗として通知します。トラック文脈の付加と PEG 失敗の解釈は呼び出し側の xref:compiler.adoc[`sxmml-compile-string!`] が担当します。

共通コマンド層が送出する既知の `<sxmml-value-error>`（音長 0、分解能を超える付点、`L` や反復の規則違反など）は、公開パーサーの実行境界（`%make-parser-with-context`）で同じ本文の `<sxmml-mml-syntax-error>` へ変換します。

== 公開手続き

[[ref-mml-make-sxmml-mml-parser]]
=== `(make-sxmml-mml-parser ctx)`

通常 MML 用のトップレベルパーサーを返します。`%make-parser-with-context` で `$note-commands` にコンテキスト `ctx` を束縛し、`<sxmml-value-error>` を `<sxmml-mml-syntax-error>` へ変換する境界を設けます。

[[ref-mml-make-sxmml-rhythm-parser]]
=== `(make-sxmml-rhythm-parser ctx)`

リズム MML 用のトップレベルパーサーを返します。`%make-parser-with-context` で `$rhythm-commands` にコンテキスト `ctx` を束縛し、`<sxmml-value-error>` を `<sxmml-mml-syntax-error>` へ変換する境界を設けます。

== 解析コンテキストと構築補助（非公開）

[[ref-mml-sxmml-mml-context]]`(sxmml-mml-context [ctx])`::
現在の `<sxmml-mml-context>` を保持するパラメータです。初期値は新規の `<sxmml-mml-context>` です。引数なしで現在値を返し、`ctx` を渡すと現在値を変更して旧値を返します。

[[ref-mml-rope-to-number]]`(rope\->number rope)`::
PEG の rope を文字列化して `string\->number` を適用します。数値として解釈できない rope は `#f` になります。

[[ref-mml-rope-to-positive-number]]`(rope\->positive-number rope :optional (message "invalid tick length: ~s (expected a positive exact integer)"))`::
`rope\->number` の結果が正の正確な整数（`exact-integer?` かつ `positive?`）であることを検査して返します。違反時は `message` と値を本文とする `<sxmml-mml-syntax-error>` を送出します。tick 指定（`%`）の解析で使用します。先頭の 0 は数値に影響しません。

[[ref-mml-rope-to-symbol]]`(rope\->symbol rope)`::
PEG の rope を文字列経由でシンボルへ変換して返します。

[[ref-mml-change-sign]]`(change-sign number)`::
`(* number -1)` を返します。状態は変更しません。

[[ref-mml-internal-parser-return]]`(%$return expr ...)`::
非公開マクロです。入力を消費せず、パーサー実行時に `expr ...` を評価して成功値として返す PEG パーサーへ展開します。

[[ref-mml-registered-command]]`($registered-command table)`::
任意の 1 文字と直後の空白を読み、ハッシュ表 `table` に登録されたパーサーで残りの入力を解析するパーサーを返します。未登録文字は `unknown MML command: "<文字>"` で `$raise` します。

[[ref-mml-internal-braced-parameter]]`($braced-parameter parser)`::
開き波括弧 `{` と直後の空白、閉じ波括弧 `}` と直前の空白を読み捨て、内部を `parser` で解析するパーサーを返します。

[[ref-mml-internal-make-mml-value-parser]]`(%make-mml-value-parser param class proc)`::
`param` と直後の空白を読み、結果に `proc` を適用した値を `:value` として `class` のインスタンスを返すパーサーを作ります。

[[ref-mml-internal-make-mml-command-parser]]`(%make-mml-command-parser class)`::
引数を取らずに `class` のインスタンスを返すパーサーを作ります。

[[ref-mml-internal-make-mml-slots-parser]]`(%make-mml-slots-parser param class proc slots)`::
複数値を読み、各値へ `proc` を適用して `slots` の順に初期化引数へ並べて `class` のインスタンスを作るパーサーを返します。モジュール内に呼び出し元はありません。

[[ref-mml-internal-make-mml-context-value-parser]]`(%make-mml-context-value-parser param command proc)`::
`param` と直後の空白を読み、`(command (sxmml-mml-context) (proc data))` を実行してその戻り値を返すパーサーを作ります。

[[ref-mml-internal-make-parser-with-context]]`(%make-parser-with-context parser ctx)`::
`sxmml-mml-context` を `ctx` に束縛して `parser` を実行し、送出された `<sxmml-value-error>` を同じ本文の `<sxmml-mml-syntax-error>` へ変換するパーサーを返します。未知の Gauche 例外はそのまま通します。

[[ref-mml-internal-proc-note-number]]`(%proc-note-number name accidentals)`::
音名文字 `name`（`a`～`g`）と `+` / `-` 文字のリスト `accidentals` から半音番号と変化量を求め、`sxmml-command-note-pitch` で現在のオクターブと移調値を加えた音高を返します。

[[ref-mml-dot-count]]`($dot-count required?)`::
連続する `.` の個数を数えて返し、後続文字を消費せず残すパーサーを作ります。付点がない場合、`required?` が真なら解析失敗、偽なら `0` を返します。

[[ref-mml-internal-make-note-length-parser]]`(%make-note-length-parser $number $dots)`::
分母パーサー `$number`、空白、付点数パーサー `$dots` を順に読み、現在の文脈と `sxmml-resolution-get` を `sxmml-command-note-length\->ticks` へ渡すパーサーを作ります。

[[ref-mml-internal-make-rhythm-command-parser]]`(%make-rhythm-command-parser param class proc)`::
楽器指定 `$rhythm-type` と値 `param` を読み、`%rhythm-types\->initargs` で楽器スロットへ `(proc data)` を割り当てた `class` のインスタンスを返すパーサーを作ります。

[[ref-mml-internal-rhythm-type-to-symbol]]`(%rhythm-type\->symbol type)`::
リズム楽器文字 `b`・`s`・`t`・`c`・`h`・`i` をそれぞれ `bass`・`snare`・`tom`・`cymbal`・`hihat`・`rimshot` のシンボルへ変換します。

[[ref-mml-internal-rhythm-types-to-initargs]]`(%rhythm-types\->initargs types val)`::
楽器文字のリスト `types` を、`:bass`・`:snare` などの初期化キーワードと値 `val` の交互リストへ変換します。

== 共通構文と音符・音長のパーサー（非公開）

この節と以降の節の各項目は `parser.peg` のパーサー値であり、単独の Scheme 引数は取りません。

[[ref-mml-parser-space]]`$space`::
0 文字以上の空白を読み捨てます。

[[ref-mml-parser-number]]`$number`::
符号なしの数字 1 文字以上を読み、rope として返します。

[[ref-mml-parser-integer]]`$integer`::
任意の `+` / `-` に続く数字 1 文字以上を読みます。符号だけでは一致しません。

[[ref-mml-parser-parameter]]`$parameter`::
裸の数字（`$number`）または波括弧内の非空白・非波括弧文字列を読みます。

[[ref-mml-parser-number-parameter]]`$number-parameter`::
裸の数字または波括弧内の数字を読みます（符号不可）。

[[ref-mml-parser-integer-parameter]]`$integer-parameter`::
裸または波括弧内の符号付き整数を読みます。

[[ref-mml-parser-multiple-parameters]]`$multiple-parameters`::
波括弧内の 1 個以上の非空白・非波括弧トークンを読みます。通常・リズムの命令表には登録されていません。

[[ref-mml-parser-note-name]]`$note-name`::
`a`～`g` と変化記号から `%proc-note-number` で確定した音高、`r` の場合は `#f` を返します。IR はまだ生成しません。

[[ref-mml-parser-note-length]]`$note-length`::
分母と任意の付点、または付点のみの音長指定を tick 数へ換算します。解像度で表せない付点はエラーになります。

[[ref-mml-parser-optional-note-length]]`$optional-note-length`::
分母・付点を省略可能にした音長パーサーです。分母省略時は現在のコンテキストの `default-length` を使います。

[[ref-mml-parser-tick-length]]`$tick-length`::
`%` に続く数字を `rope\->positive-number` で正の正確な整数 tick 値へ変換します。ゼロ埋めした正整数は受理し、`0` や符号・小数は不可です。

[[ref-mml-parser-duration]]`$duration`::
基本音長（`$tick-length` または `$optional-note-length`）に、`&` で連結された追加音長（`$tick-length` または `$note-length`）をすべて加算した tick 数を返します。`$note`・`$rhythm-on`・`$rhythm-rest`・`$portamento` が使用します。

[[ref-mml-parser-note]]`$note`::
`$note-name` と `$duration` を読み、音高が真なら `sxmml-command-note!` で `<sxmml-mml-note>`、休符（`#f`）なら `sxmml-command-rest!` で `<sxmml-mml-rest>` を返します。同時に `current-ticks` と `ticks-statistics` を更新します。

== 通常 MML コマンドのパーサー（非公開）

`$length`・`$octave`・`$octave-up`・`$octave-down`・`$transpose-env` は現在のコンテキストを更新して `#f` を返します（`sxmml.compiler` は IR 収集時に `#f` を除きます）。その他のコマンドは対応する IR オブジェクトを返します。

[[ref-mml-parser-length]]`$length`::
`l` コマンド（通常・リズム共通）。`sxmml-command-default-length-set!` で `default-length` を更新します。

[[ref-mml-parser-octave]]`$octave`::
`o` コマンド。`sxmml-command-octave-set!` で `current-octave` を更新します。

[[ref-mml-parser-octave-up]]`$octave-up`::
`>` コマンド。`sxmml-command-octave-shift!` で `current-octave` を 1 増やします。

[[ref-mml-parser-octave-down]]`$octave-down`::
`<` コマンド。`sxmml-command-octave-shift!` で `current-octave` を 1 減らします。

[[ref-mml-parser-volume]]`$volume`::
符号なし音量から `<sxmml-mml-volume>` を作ります。

[[ref-mml-parser-volume-change]]`$volume-change`::
符号付き差分値から `<sxmml-mml-volume-change>` を作ります。

[[ref-mml-parser-volume-command]]`$volume-command`::
`v` コマンド。`$volume`、または `*` に続く `$volume-change` を解析します。

[[ref-mml-parser-volume-up]]`$volume-up`::
`)` コマンド。`sxmml-command-volume-up` で `volume-delta` 分の `<sxmml-mml-volume-change>` を返します。

[[ref-mml-parser-volume-down]]`$volume-down`::
`(` コマンド。`sxmml-command-volume-down` で負の `volume-delta` 分の `<sxmml-mml-volume-change>` を返します。

[[ref-mml-parser-pan]]`$pan`::
`p` コマンド。符号なし値から `<sxmml-mml-pan>` を作ります。

[[ref-mml-parser-gate-time]]`$gate-time`::
`q` コマンド。符号なし値から `<sxmml-mml-gate-time>` を作ります。

[[ref-mml-parser-tie]]`$tie`::
`&` コマンド。値なしの `<sxmml-mml-tie>` を作ります。

[[ref-mml-parser-transpose]]`$transpose`::
符号付き値から `<sxmml-mml-transpose>` を作ります。

[[ref-mml-parser-transpose-env]]`$transpose-env`::
`sxmml-command-note-transpose-set!` で `current-transpose` を更新します。

[[ref-mml-parser-transpose-change]]`$transpose-change`::
符号付き差分値から `<sxmml-mml-transpose-change>` を作ります。

[[ref-mml-parser-transpose-command]]`$transpose-command`::
`K` コマンド。`$transpose`、`$` に続く `$transpose-env`、`*` に続く `$transpose-change` のいずれかを解析します。

[[ref-mml-parser-tempo]]`$tempo`::
`t` コマンド。符号なし値から `<sxmml-mml-tempo>` を作ります。

[[ref-mml-parser-tempo-absolute]]`$tempo-absolute`::
`T` コマンド。符号なし値から `<sxmml-mml-tempo-absolute>` を作ります。

[[ref-mml-parser-detune]]`$detune`::
`D` コマンド。符号付き値から `<sxmml-mml-detune>` を作ります。

[[ref-mml-parser-loop]]`$loop`::
`L` コマンド（通常・リズム共通）。`sxmml-command-loop!` を呼び `<sxmml-mml-loop>` を返します。反復内での使用や同一トラック内での重複（登録をまたぐ 2 個目を含む）は `<sxmml-mml-syntax-error>` になります。

[[ref-mml-parser-repeat-start]]`$repeat-start`::
`[` コマンド（通常・リズム共通）。`sxmml-command-repeat-start!` で反復スタックと tick スタックを積み、`<sxmml-mml-repeat-start>` を返します。

[[ref-mml-parser-repeat-break]]`$repeat-break`::
`:` コマンド（通常・リズム共通）。`sxmml-command-repeat-break!` で脱出位置の tick と設定を記録し、`<sxmml-mml-repeat-break>` を返します。反復外や同一反復内の 2 個目以降は `<sxmml-mml-syntax-error>` になります。

[[ref-mml-parser-repeat-end]]`$repeat-end`::
`]` コマンド（通常・リズム共通）。回数を読んで `sxmml-command-repeat-end!` を呼び、`<sxmml-mml-repeat-end>` を返します。開始前の出現や正の正確な整数以外の回数は `<sxmml-mml-syntax-error>` になります。

[[ref-mml-parser-voice]]`$voice`::
`@` コマンド。`$parameter` をシンボル化して `<sxmml-mml-voice>` を作ります。

[[ref-mml-parser-envelope]]`$envelope`::
`E` コマンド。`$parameter` をシンボル化して `<sxmml-mml-envelope>` を作ります。

[[ref-mml-parser-lfo-set]]`$lfo-set`::
`{ id ch }` 形式（空白区切り 2 トークンをシンボル化）または裸の数字（`$number` をシンボル化、`channel` は `#f`）から `<sxmml-mml-lfo>` を作ります。

[[ref-mml-parser-lfo-switch]]`$lfo-switch`::
`t`（`#t`）または `f`（`#f`）と省略可能なチャンネル引数（`$parameter`）から `<sxmml-mml-lfo-switch>` を作ります。

[[ref-mml-parser-lfo-command]]`$lfo-command`::
`M` コマンド。`$lfo-set`、`$lfo-switch` の順に試行します。

[[ref-mml-parser-portamento-pitch]]`$portamento-pitch`::
ポルタメント内の 1 音分の音高パーサーです。0 回以上のオクターブ操作（`o`・`>`・`<`）で現在のコンテキストを更新した後に音名 `a`～`g` と変化記号を読み、`%proc-note-number` で確定音高を返します。

[[ref-mml-parser-portamento]]`$portamento`::
`/` コマンド。`{` に続く始点・終点の 2 つの `$portamento-pitch` と `}`、さらに `$duration` を読み、`sxmml-command-portamento!` で `<sxmml-mml-portamento>` を返します。始点音高は終点前のオクターブ操作より先に確定し、解析時に tick 累計と統計を更新します。

[[ref-mml-parser-noise-frequency]]`$noise-frequency`::
`w` コマンド。符号なし値から `<sxmml-mml-noise-frequency>` を作ります。

[[ref-mml-parser-output-switch]]`$output-switch`::
`P` コマンド。符号なし値から `<sxmml-mml-output-switch>` を作ります。

[[ref-mml-parser-note-commands]]`$note-commands`::
通常 MML の 1 コマンド分のパーサーです。先行空白を読み捨てた後、`$note` または `+($registered-command *note-command*)+` を適用します。

== リズム MML コマンドのパーサー（非公開）

リズム楽器文字は `b`・`s`・`t`・`c`・`h`・`i` の 6 種です。通常 MML と共通の `$loop`（`L`）・`$repeat-start`（`[`）・`$repeat-break`（`:`）・`$repeat-end`（`]`）・`$length`（`l`）も `+*rhythm-command*+` に登録されています。

[[ref-mml-parser-rhythm-type]]`$rhythm-type`::
`b`・`s`・`t`・`c`・`h`・`i` の 1 文字以上（波括弧あり・なし両対応）を読みます。

[[ref-mml-parser-rhythm-on]]`$rhythm-on`::
`@` コマンド。`$rhythm-type` と `$duration` を読み、`sxmml-command-rhythm-on!` で `value` が `#t` の `<sxmml-rhythm-emit>` を返します。tick 累計と統計を更新します。

[[ref-mml-parser-rhythm-off]]`$rhythm-off`::
`!` コマンド。`$rhythm-type` を読み、`value` が `#f`、指定楽器スロットが `#t` の `<sxmml-rhythm-emit>` を作ります。`ticks` は設定せず、tick 累計・統計は更新しません。

[[ref-mml-parser-rhythm-rest]]`$rhythm-rest`::
`r` コマンド。`$duration` を読み、`sxmml-command-rest!` で `value` が `#f` の `<sxmml-mml-rest>` を返します。tick 累計と統計を更新します。

[[ref-mml-parser-rhythm-volume]]`$rhythm-volume`::
`V` コマンド。裸の数字（`$number`）を `value` とする `<sxmml-rhythm-volume>` を作ります。

[[ref-mml-parser-rhythm-instrument-volume]]`$rhythm-instrument-volume`::
`v` コマンド。楽器ごとの音量（`$number`）を各楽器スロットへ設定した `<sxmml-rhythm-volume>` を作ります。

[[ref-mml-parser-rhythm-instrument-volume-up]]`$rhythm-instrument-volume-up`::
`)` コマンド。楽器ごとの符号付き整数（`$integer`）をそのまま各楽器スロットへ設定した `<sxmml-rhythm-volume-change>` を作ります。

[[ref-mml-parser-rhythm-instrument-volume-down]]`$rhythm-instrument-volume-down`::
`(` コマンド。楽器ごとの符号付き整数（`$integer`）の符号を反転して各楽器スロットへ設定した `<sxmml-rhythm-volume-change>` を作ります。

[[ref-mml-parser-rhythm-pan]]`$rhythm-pan`::
`p` コマンド。楽器ごとのパン値（`$number`）を各楽器スロットへ設定した `<sxmml-rhythm-pan>` を作ります。

[[ref-mml-parser-rhythm-commands]]`$rhythm-commands`::
リズム MML の 1 コマンド分のパーサーです。先行空白を読み捨てた後、`+($registered-command *rhythm-command*)+` を適用します。
