= `sxmml.environment` の状態管理
:toc: left

解像度の既存の検査はvalue-error、独自マクロの形式違反はform-syntax-errorです。取得できるフォーム位置は既知のエラーだけへ独立したconditionとして添えます。値の式の未定義変数や引数個数など、Gauche由来の失敗は包み直しません。

`sxmml.environment` には環境と登録表を操作する 35 の定義があり、そのうち 32 を公開します。パラメータ、マクロ、ハッシュ表の動作は Gauche 0.9.15 に従います。MML 記述者向けの使用例は xref:../sxmml-reference-manual.adoc[公開機能リファレンス]を参照してください。

状態を保持する本体は xref:classes.adoc#ref-classes-class-sxmml-environment[`<sxmml-environment>`] です。`make-parameter` で作る束縛は手続きであり、引数なしで現在値を返し、値を一つ渡すと動的な現在値を変更して旧値を返します。表の設定手続きは、特記しない限り現在の環境オブジェクト内の slot または表を変更します。登録手続きの戻り値は呼び出し側では使用していません。`get` の未登録時の挙動は項目ごとに異なります。

モード情報はbackendの読込み時に共有表`%sxmml-modes`へ登録し、楽曲環境は選択情報だけを保持します。`<sxmml-mode>`のnameはsymbol、aliasesはsymbolのリスト、setupは手続きまたは#f、backendは手続き、output-extensionは文字列または#fです。setupは引数なしで呼びます。必須項目の省略も登録時に値エラーとなり、手続きの引数個数は事前検査しません。型違反の本文は`invalid mode`・`invalid mode name`・`invalid mode aliases`・`invalid mode setup`・`invalid mode backend`・`invalid mode output extension`で値と期待型を示します。

CLIとソースのマクロ双方で指定した場合はCLI側を優先し、明示的な選択手続きによる変更は認めます。通常の分岐構文でselected?を使えます。動作はlink:../behavior-spec.md#入力と実行順[外部動作仕様]を参照してください。

== LFO・エンベロープの登録

定義名は `sxmml-form-name->symbol` でsymbol／identifier・数値からMML用の名前へ正規化します。種類は `identifier?` で検査し、quoteによって登録時にはsymbolになります。メタデータキーはsymbol／identifierだけを受け、元のsymbolの名前を小文字へそろえます。トラック名もsymbol／identifierを検査してquoteし、複数形式では全要素を検査します。登録手続きや、種類・キー・トラック名へMML定義名の文字制限は追加しません。

`define-lfo` と `define-envelope` は、共通の `%define-lfo/envelope-expand` で展開し、実行時に対応する `set!` 手続きを呼びます。`type`（LFO・エンベロープの種類。波形の種類）はリテラルのシンボルで、省略すると `default` です。枠の中の値は式として評価し、`(list 値 …)` を登録します。形は展開時に検査し、誤りは xref:form.adoc[`sxmml.form`] の `sxmml-form-error` で定義の位置を付けて投げます。既知の入力エラーだけに `sxmml-form-call` が独立した位置conditionを添えます。値の式のGaucheエラーは包み直しません。未登録 ID の取得は、`get` に既定値を渡していないためハッシュ表の検索エラーになります。

直接のcontext・登録表編集は許容し、検索時の重複拒否は追加しません。一対一対応を崩した状態では、候補の選択と、それに依存する生成物の再現性を保証しません。削除・全消去でpartは再利用可能になります。

`sxmml-track-clear!` は引数なしでトラック表を全件削除します。次の例では `G` と `H` の両方を削除します。

[source,console]
----
$ gosh -I. -e '(use sxmml)' -e '(define-track (G H))' -e '(print (sort (map symbol->string (sxmml-track-list))))' -e '(sxmml-track-clear!)' -e '(print (sxmml-track-list))'
(G H)
()
----

引数を渡すと arity エラーになります。
