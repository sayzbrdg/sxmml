= `sxmml.compiler` のコンパイル処理
:toc: left

PEGドライバのparse-errorはcompilerの境界でmml-syntax-errorへ変換し、元のPEG conditionは保持しません。明示的な理由、または `invalid MML syntax near "..."` を本文に使います。トラックは本文へ埋め込みません。既知のエラーには取得できるtrack-contextを添えます。非文字列引数はvalue-error、未定義トラックはreference-error、未知のGaucheエラーはそのまま通します。

`sxmml.compiler`は五つの手続きと二つのマクロを公開し、非公開の展開手続き一つを共用します。通常 MML とリズム MML のパーサーは xref:mml.adoc[`sxmml.mml`]、登録先の状態は xref:environment.adoc[`sxmml.environment`] を参照してください。パーサー、generator、マクロの動作は Gauche 0.9.15 に従います。

== 手続き

`sxmml-compile-string!` 系は MML を sxmml IR の列へコンパイルし、`ctx` と合わせて二つの値を返します。`ctx` の解析状態はパーサーによって更新されます。generatorから収集するときに`gfilter`で`#f`を除き、IR列の追加走査は行いません。文脈命令だけの入力では、解析を最後まで行って空のIR列を返します。EOFは終端、`#f`はIRなしの解析結果として区別します。トラックへの登録はここでは行わず、`mml` / `rhythm` マクロが `sxmml-ir-register!` を呼びます。文字列以外の入力は明示的なエラー、PEG の `<parse-error>` はトラック文脈を添えた構文エラーとして投げ直します。

PEG の失敗種別 `type` が `fail-error` で、失敗情報 `objects` がタグと単一の `(fail-message . 文字列)` の構造なら、その文字列を本文にし、トラック情報は別のconditionで添えます。たとえば `$raise` で伝えた未登録命令の理由は `unknown MML command: "x"` となります。タグの値や理由の文言には依存しません。それ以外は残りの入力を使う既存の `invalid MML syntax near "..."` の表記を使い、トラック文脈は別に保持します。

== ソース中で使うマクロ

両マクロはトラック名一つ、または一つ以上のトラック名のリストを受けます。`body ...` の Scheme 式は実行時に評価され、`write-tree` で文字列へ組み立てられます。本文の各式の評価と文字列化は一度だけ行い、`let`で共有します。その後、各トラックの解析文脈で、指定順にコンパイル・登録します。生成済みIRは共有しません。本文が空の形も受理します。共有する式同士の評価順はsxmml独自の保証にしません。名前は`identifier?`で検査してquoteでsymbol化します。不正な書式・空の対象リスト・不正な名前は、`invalid mml form: expected (mml track body ...) or (mml (track ...) body ...)`、`mml requires at least one track name`、`invalid mml track name: 0 (expected a symbol)`のような位置付きフォーム構文エラーです。`rhythm`も同じ構成です。未登録トラックとMML構文エラーは実行時に失敗し、フォーム位置と取得できるトラック情報を保持します。未知のGauche例外は包み直しません。マクロ形式の詳細と利用例は xref:../sxmml-reference-manual.adoc[公開機能リファレンス]を参照してください。

|[[ref-compiler-mml]]`(mml track body ...)` / `(mml (track ...) body ...)` |本文を通常 MML として `sxmml-compile-track-mml` に渡す式へ展開 |得たオブジェクト列を `sxmml-ir-register!` でトラックへ登録 |link:../../sxmml/compiler.scm[compiler.scm]

|===

== コンパイル例

リポジトリのルートで実行します。既定の解像度は 24 tick です。

[source,console]
----
$ gosh -I. -e '(use sxmml)' -e '(define-track G)' -e '(mml G "c8r8")' -e '(print (caar (slot-ref (sxmml-track-get (quote G)) (quote current-ticks))))'
24
----
