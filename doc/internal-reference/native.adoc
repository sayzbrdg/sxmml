= `sxmml.native` の C 接続
:toc: left

必須の共有ライブラリ `sxmml_native` を読み込み、反復圧縮の接続手続きを公開します。楽曲記述用の `sxmml` からは公開しません。型や構築子は呼び出し時に解決します。汎用の反復圧縮は `sxmml.optimizer` を読み込まずに使えます。固定 IR 比較は、`sxmml.optimizer` が定義する反復ブロックの型とアクセサを使います。

モジュールの定義は link:../../sxmml/native.scm[native.scm] にあります。このモジュールは 3 手続きを定義し、すべて公開します。

== 接続手続き

[[ref-native-sxmml-native-repeat-tree-compress]]
=== `(sxmml-native-repeat-tree-compress items weights same? settings)`

xref:repeat-tree.adoc[`repeat-tree-compress`] で型や要素数などの検査を済ませた入力を受け、費用と木を 2 値で返します。
二要素を比較するたびに、利用者が指定した Scheme 手続き `same?` を呼びます。比較結果は真偽値でなければなりません。

実装は link:../../src/lib/sxmml_nativelib.scm[sxmml_nativelib.scm] にあります。

[[ref-native-sxmml-native-ir-compress]]
=== `(sxmml-native-ir-compress elements weights settings)`

optimizer が組み立てた要素・重みのベクタと反復設定を受け取り、費用と木を 2 値で返します。
比較には下記の固定 IR 比較を使います。数値の範囲は C コアを呼び出す際に検査します。

[[ref-native-make-sxmml-native-ir-comparison]]
=== `(make-sxmml-native-ir-comparison)`

同じ固定 IR 比較を Scheme から呼び出す二引数の手続きを返します。テスト支援が復元した IR を調べる際に使います。
比較手続きは GC 管理下の比較用データを保持します。固定 IR 圧縮とこの比較手続きの実装は link:../../src/lib/sxmml_optimizerlib.scm[sxmml_optimizerlib.scm] にあります。

== 固定 IR 比較

通常の命令は、実際のクラスと全スロットを比較します。派生クラスが追加したスロットも含めます。対応するスロットが両方とも未束縛なら等しく、片方だけが未束縛なら異なります。両方に値があれば `Scm_EqualP` で比較します。

音符とタイをまとめた要素は、長さと各要素を比較します。既存の反復ブロックは、回数、脱出位置の有無、前半と後半の要素を比較します。
こうした要素への組み立て、重みの算出、区間分けと IR への復元は xref:optimizer.adoc[optimizer の Scheme 側]が担当します。

スロットの参照には Gauche のアクセサ情報を使います。該当クラスのインスタンススロットを直接参照できる場合は C 側で読みます。仮想スロットなどは `slot-bound?` と `slot-ref` に、クラス再定義時のクラス取得は `class-of` に委ねます。アクセサのキャッシュは圧縮一回、または生成した比較手続き一つの中で保持します。
`Scm_EqualP` や Gauche のスロット操作が内部で Scheme を呼ぶことがあります。比較やスロット操作で発生した例外は呼び出し元へ伝わります。

== C コアと結果変換

C コアは要素を添字で扱い、重み・反復設定と C の比較関数を受け取ります。共通接頭辞の長さを求め、区間ごとの費用と全体の連結を計算します。復元したノード配列では、子が親より先に並びます。
契約と実装は link:../../src/lib/sxmml_repeat_tree.h[sxmml_repeat_tree.h] と link:../../src/lib/sxmml_repeat_tree.c[sxmml_repeat_tree.c] を参照してください。

共通接続では Scheme の数値を C の整数に変換します。個々の重みと制御費用は `uint64_t`、回数と窓幅は `size_t` の範囲に限ります。重みの総和と作業領域の大きさは、C コアでも検査します。
計算が終わると、ノード配列を4種類の record 構築子で Gauche の木に変換します。入力 IR はコピーしません。
作業領域は変換後に解放し、例外で中断した場合も解放してから元の例外を伝えます。

接続の実装は link:../../src/lib/sxmml_native.c[sxmml_native.c] にあります。
