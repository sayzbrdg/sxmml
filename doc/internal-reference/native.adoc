== 責任境界と比較

IRの構造化、音符とタイのグループ化、重み、制御境界、IRへの復元はoptimizerのScheme側が担当します。固定IR比較はoptimizer所属のCiSEで定義し、実際のクラスと全スロットを比較します。クラスの親子関係で同じとみなさず、未束縛どうしは同じ、未束縛と束縛値は異なるとします。束縛値は `Scm_EqualP` で比較します。派生クラスの追加スロットも含みます。

音符とタイのグループは長さと各要素、既存反復は回数・脱出の有無・前半と後半を比較します。既存反復の型と解釈はoptimizerの責務です。通常スロットは対応する公開アクセサ情報を確認してCから読み、仮想スロット等はGaucheの `slot-bound?`・`slot-ref` に委ねます。クラス再定義で更新が必要な場合もGaucheの経路を使います。クラス情報は圧縮一回の文脈内だけに保持します。

`Scm_EqualP` や特殊なスロット操作が内部でSchemeを呼ぶことは許容します。IR圧縮で比較のたびに任意のScheme比較手続きを呼び戻す設計にはしません。比較やGauche操作で発生した例外は包み直しません。

== Cコアと結果変換

link:../../src/lib/sxmml_repeat_tree.h[Cコアの契約]とlink:../../src/lib/sxmml_repeat_tree.c[実装]はGauche・IRを知らず、添字・重み・設定とC比較関数／文脈を受けます。LCP、区間DP、全体連結、子を先に並べたノード配列への復元を担当します。

link:../../src/lib/sxmml_native.c[共通接続]は数値の変換と範囲検査、コア呼出し、既存の構築子によるGaucheの木への変換を担当します。重み・制御費用・重み総和はuint64_t、添字・回数・窓幅・領域サイズはsize_tの範囲です。選ばれないRepeat・Final候補の加算は行わず、範囲外エラーにしません。

Cの領域は一回の実行に所属し、木への変換後に解放します。Gaucheの例外による巻戻しでも同じ領域を解放して元の例外を伝播します。入力IRのコピーは作りません。通常実行では結果の再検査を行わず、木と復元IRの検査はテスト支援へ配置します。
