= sxmml 開発者向け内部リファレンス
:toc: left

この索引は、sxmml を保守・改修する際に内部定義を名前から探すためのものです。動作環境は Gauche 0.9.15 です。内部の名前は MML 記述者向け API を示しません。公開機能の使い方は xref:../sxmml-reference-manual.adoc[MML 記述者向けリファレンス]、MML 文字列の記法は xref:../sxmml-mml-manual.adoc[MML コマンドマニュアル]を参照してください。

モジュール直下の手続き 258 件、クラス 52 件、マクロ 12 件、合計 322 件を掲載します。実験的な `sxmml.backend.pmd-binary` は公開名 7 件だけを掲載し、内部定義は xref:pmd-binary.adoc[本文]に概要だけを記します。`sxmml.scm` は各モジュールを継承し、独自の直下定義はありません。`sxmml.backend.pmd-binary` の `initialize` を除き、各モジュールには `define-method` による定義はありません。局所関数と `sxlc.in` の直下定義は範囲外です。呼び出せない表（ハッシュ表やリスト）は対象外です。

識別子の命名と改名の判断は xref:naming-conventions.adoc[命名規約]を参照してください。

== 掲載範囲と読み方

各項目から定義モジュール別の本文へ進めます。本文には呼び出し形またはクラスの初期化形、引数・値、状態や出力への作用、失敗条件、ソース位置を記しています。同名の項目はモジュール名で区別します。クラスの slot と親クラスは xref:classes.adoc[クラス一覧]を参照してください。

`define-inline` でも値がパーサー手続きなら手続きとして扱います。`make-parameter` の結果と手続きの別名も手続きに含みます。呼び出せない表（ハッシュ表やリスト）は掲載対象から除外します。公開状態は Gauche 0.9.15 の `module-exports` に基づきます。

モジュール間の流れは link:../architecture.md[構成と設計]、改修手順は link:../developer-guide.md[開発・改修手順]を参照してください。既知の不具合と利用上の制約は該当項目に記しています。
