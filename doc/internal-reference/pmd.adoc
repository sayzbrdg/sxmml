= `sxmml.backend.pmd` の共通処理
:toc: left

PMD両バックエンドで使う7つの公開手続きと、非公開の定義値検査1件を持ちます。モード登録とファイル出力は xref:pmd-source.adoc[source]・xref:pmd-binary.adoc[binary]へ分離しています。

現在の登録環境を更新するのはsetup!だけです。他の入口は定義表・IR列等を明示的に受け取り、入力を変更しません。最適化要求の整数からどの処理を選ぶかは、このPMD共通層が決めます。CLIはその対応を解釈しません。

[cols="2,4,4,1",options="header"]
|===
|名前・書式 |役割・引数 |結果・状態・失敗条件 |ソース
|[[ref-pmd-sxmml-pmd-setup-bang]]`(sxmml-pmd-setup!)` |PMD共通の初期トラック登録 |現在の登録環境へA～J・Lを登録。FMのvolume-deltaは4、PCMは16 |link:../../sxmml/backend/pmd.scm[pmd.scm]
|[[ref-pmd-sxmml-pmd-metadata-value]]`(sxmml-pmd-metadata-value metadata key)` |明示したメタデータ表から値を検査して返す |memoは文字列のリスト、他の対応キーは文字列または#f。不正な値は既存の値エラー |link:../../sxmml/backend/pmd.scm[pmd.scm]
|[[ref-pmd-sxmml-pmd-voice-number-table-compute]]`(sxmml-pmd-voice-number-table-compute voices)` |明示した音色表から番号表を作る |idの辞書順に0～255。256音色を超える場合は既存の基底sxmml-error |link:../../sxmml/backend/pmd.scm[pmd.scm]
|[[ref-pmd-sxmml-pmd-lfo-values]]`(sxmml-pmd-lfo-values lfo)` |LFOの種類と値を検査する |値のリストを返す。default・triangleを受理し、既存の項目別範囲を維持 |link:../../sxmml/backend/pmd.scm[pmd.scm]
|[[ref-pmd-sxmml-pmd-envelope-values]]`(sxmml-pmd-envelope-values envelope)` |エンベロープの種類と値を検査する |4・5・6値のリストを返し、既存の項目別範囲を維持 |link:../../sxmml/backend/pmd.scm[pmd.scm]
|[[ref-pmd-internal-pmd-definition-values]]`(%pmd-definition-values kind obj types ranges expected)` |LFO・エンベロープの共通の値検査 |種類、値の数、正確な整数性、項目別の範囲を検査。入力を変更しない |link:../../sxmml/backend/pmd.scm[pmd.scm]
|[[ref-pmd-sxmml-pmd-check-obsolete-metadata]]`(sxmml-pmd-check-obsolete-metadata metadata)` |明示した表のfilenameメタデータを確認 |指定があれば既存の警告を標準エラーへ出す。出力先には使用しない |link:../../sxmml/backend/pmd.scm[pmd.scm]
|[[ref-pmd-sxmml-pmd-ir-optimize]]`(sxmml-pmd-ir-optimize ir level)` |整数要求に応じた最適化を選ぶ |0以下は入力列、1は局所整理、2は基本組合せ、3は通常反復圧縮付き、4以上は展開付き。入力を変更しない |link:../../sxmml/backend/pmd.scm[pmd.scm]
|===

呼び出せない規則表は索引件数に含めません。`%pmd-lfo-types`・`%pmd-lfo-ranges`・`%pmd-envelope-types`・`%pmd-envelope-ranges`の4表で、従来の種類・個数・範囲を定めます。共通登録の検査は、手作りIRも受け取るバックエンドの検査の代わりにはしません。
