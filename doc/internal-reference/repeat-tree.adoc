= `sxmml.repeat-tree` の局所反復木による列の圧縮
:toc: left

`sxmml.repeat-tree` は、同値比較できる要素の列を、展開すると元の列になる木（局所反復木）のうち保存費用が最小のものに圧縮します。sxmml のクラスには依存しません。手続き 29 件とクラス（record 型）5 件を定義し、手続き 24 件を公開します。`sxmml` はこのモジュールを `extend` しません。record 型と整数は Gauche 0.9.15 の動作に従います。

== 取り込み元と仕様との違い

repeat-tree の Gauche 移植（`ports/gauche`、実装 ID `gauche-all-periods/2`、仕様 ID `local-repeat-tree/1`、commit `7e521ec46950b9c9a42424ea1199db5f2170a766`）をもとにしています。開発者は sxmml と同じで、sxmml と同じ 3-clause BSD として取り込み、sxmml に合わせて変更しました。

`local-repeat-tree/1` との違いは次のとおりです。

* 葉の費用を要素ごとの重み（正の整数）にしました。仕様 §4 では、葉の費用を変える拡張は適用域外です。
* 窓幅 W を加えました。長さ W 以下の区間だけを区間 DP で解き、列全体は長さ W 以下のブロックの連結として最小にします。W < n では探索範囲を狭めるので、`local-repeat-tree/1` への適合は名乗りません。
* 有限の深さの層を除き、深さ無制限の 1 層だけで解きます。入れ子の上限は呼び出し側が検査します。
* 入力長と費用表の組数の受付上限を除き、エラーの分類を `error` にまとめ、根の記述を整数に符号化しました。適合試験用の JSON は取り込んでいません。

W ≥ n のとき、仕様 §6 の参照算法を重み付きに一般化したものと同じ費用・同じ木を返します。同率では raw、分割点の昇順、周期の昇順、全体の連結の始点の昇順で、厳密に小さい候補だけが選ばれます。重み付きへの一般化の証明は、repeat-tree の研究側の課題です。

時間は O(nW²)、領域は O(nW)、比較手続きの呼び出しは O(nW) 回です（n は列の長さ）。成功の前に、探索とは別に木をたどって費用・回数・展開を検査します。

== 使用例

ABABA を、Final の回数 3（制御費用 0）で圧縮します。sxmml のリポジトリルートで実行します。

[source,console]
----
$ gosh -I. -e '(use sxmml.repeat-tree)' -e '(receive (cost tree) (repeat-tree-compress #(a b a b a) #(1 1 1 1 1) eq? (make-repeat-tree-settings (quote ()) (quote ((3 . 0))) #t 256)) (print cost " " (final? tree) " " (final-count tree)))'
2 #t 3
----
