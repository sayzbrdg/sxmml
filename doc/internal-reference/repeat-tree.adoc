= `sxmml.repeat-tree` の反復木による列の圧縮
:toc: left

`repeat-tree-compress` は、要素の列を、展開すれば入力と同値な列になる木に変換します。保存に必要な費用の小さい木を、指定された反復回数と窓幅の範囲で探します。
要素をどう比較するかは呼び出し側が指定します。楽曲の IR を組み立て直す側の規則は xref:optimizer.adoc[IR 列最適化]を参照してください。

圧縮本体は C 拡張で実行します。実装は link:../../sxmml/repeat-tree.scm[repeat-tree.scm] にあります。
このモジュールは26手続きと5 record 型を定義し、23手続きを公開します。楽曲記述用の `sxmml` からは公開しません。

== 木と費用

葉は入力位置を指します。連結、回数付きの反復、最終回に後半を省く反復を組み合わせて木を作ります。反復の本文もこの木で表すので、入れ子にできます。

葉の費用は、その位置に指定された正の整数の重みです。連結の費用は左右の和です。反復の費用は本文の費用と回数ごとの制御費用の和です。最終回に後半を省く反復では、前半と後半の費用に、その回数に対応する制御費用を加えます。

== 探索範囲

入力長を `n`、窓幅を `W` とします。動的計画法で長さ `W` 以下の区間を解き、これらの区間を連結して入力全体を覆う費用を最小にします。`W` が `n` 以上なら、設定した反復の型と回数で入力全体を表す最小費用の木を返します。`W` が `n` 未満なら、窓幅で限定した探索範囲での最小費用です。呼び出し側が出力形式に合わせて結果の深さを判断します。

各区間では、反復を使わず葉を並べた候補、分割点の昇順、周期の昇順で比較します。全体の連結では区間の始点を昇順に比較します。費用が同じ場合は先に見つかった候補を採用します。

実際の窓幅は `n` と `W` の小さい方です。この幅を `w` とすると、探索の時間は O(nw²)、作業領域は O(nw) です。要素を比較する費用を除いた時間で、比較手続きの呼び出しは O(nw) 回です。C のノード配列は xref:native.adoc[C 接続]で Gauche の木に変換します。
費用と展開結果の独立検査は link:../../test/repeat-tree-check.scm[テスト支援]を参照してください。

同じ開発者の Gauche 実装をもとに、重み付きの葉と窓幅を使えるようにしました。ライセンスは sxmml と同じ 3-clause BSD です。

== 公開手続き

[[ref-repeat-tree-repeat-tree-compress]]
=== `(repeat-tree-compress items weights same? settings)`

`items` と `weights` には、同じ長さの空でないベクタを渡します。各重みは正の正確な整数に限ります。`settings` は `make-repeat-tree-settings` で作ります。
`same?` は要素二つを受け、真偽値を返す停止する同値関係です。同値な出現には同じ重みが必要です。この条件は呼び出し側で満たしてください。

圧縮後の費用と木を 2 値で返します。引数や設定の誤り、数値範囲外、比較結果が真偽値以外の場合はエラーになります。比較中に発生した例外は呼び出し元へ伝わります。

重み、制御費用、重み総和は `uint64_t`（最大18446744073709551615）、入力長、回数、窓幅、領域サイズは `size_t` の範囲です。採用できる費用かどうかを加算前に判定するので、費用が現在の最良値以上になる反復候補は、加算の範囲外エラーを起こさず除外します。

[[ref-repeat-tree-make-repeat-tree-settings]]
=== `(make-repeat-tree-settings repeat-costs final-costs allow-final? window)`

通常反復用の `repeat-costs` と、最終回に後半を省く反復用の `final-costs` を指定します。各表は `((回数 . 制御費用) ...)` のリストです。回数は2以上の正確な整数を重複なしの昇順で並べます。制御費用には0以上の正確な整数を指定します。

`allow-final?` は `#t` または `#f` で指定します。`#t` なら `final-costs` の反復を候補に加えます。`window` は1以上の正確な整数です。両方の費用表を検査してコピーし、設定を返します。値に誤りがあると `repeat-tree:` で始まるエラーになります。

== 使用例

ABABA を、Final の回数 3（制御費用 0）で圧縮します。sxmml のリポジトリルートでビルド後に実行します。

[source,console]
----
$ GAUCHE_DYNLOAD_PATH="$PWD/build${GAUCHE_DYNLOAD_PATH:+:$GAUCHE_DYNLOAD_PATH}" gosh -I. -e '(use sxmml.repeat-tree)' -e '(receive (cost tree) (repeat-tree-compress #(a b a b a) #(1 1 1 1 1) eq? (make-repeat-tree-settings (quote ()) (quote ((3 . 0))) #t 256)) (print cost " " (final? tree) " " (final-count tree)))' -E exit
2 #t 3
----
