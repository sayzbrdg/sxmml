# sxmml 製品概要・用語集

この文書は、sxmml の目的、利用場面、責任範囲を利用者と開発者に示す。動作環境は Gauche 0.9.15 である。

## 製品の目的と利用場面

**目的:** sxmml は、Scheme を使用して柔軟な MML 記述と MML オブジェクト操作を可能とする MML トランスレータである。

**対象利用者:** 古い MML の制約によって思い通りの記述ができずに困っている MML 記述者。

**代表的な利用場面:** 既存ドライバー向け MML では手動で行うしかなかった最適化を自動化する。現在の最適化の種類と制約は[要求仕様](requirements.md)に記す。

現在提供する出力形式は PMD 向け MML である。製品が生成する成果物の種類は MML に限定しない。

現在の利用の流れは次のとおりである。

1. 利用者が Gauche の Scheme 式と `mml` / `rhythm` 等を含むソースファイルを用意する。
2. `sxlc` がソースファイルを読み込み、指定された出力モードまたはソース内で選択されたモードに従って変換する。
3. sxmml が PMD 向け MML を生成する。

## 機能と責任の境界

| 領域 | 現在提供する機能 | 今後の扱い |
| --- | --- | --- |
| 入力 | `sxlc` が Gauche の Scheme ソースを読み込み、`mml` / `rhythm` で渡された文字列等を処理する | 将来の入力形式は未定 |
| 変換・出力 | PMD 向け MML ファイルを生成する | 生成物の種類は MML に限定しない |
| 最適化 | `sxlc -O` で最適化の水準を指定できる | 必須とする最適化の種類と効果の下限は未定 |
| 外部ツール | `sxlc -c` は指定コマンドを後処理として起動できる | 後処理のコマンドと結果は利用者が管理する |

## 責任範囲

sxmml の責任範囲は生成物を作るところまでである。生成物は MML に限定しないが、現在の出力は PMD 向け MML である。外部ツールが生成物を受理・利用すること、楽曲の演奏機能、音源ドライバー本体の提供は対象外とする。`sxlc -c` で後処理を起動できる。後処理の結果は利用者が確認する。

## 用語

| 用語 | 本書での意味 |
| --- | --- |
| MML | 音符、音長、音量などを文字で記す楽曲記述。sxmml の入力側と PMD 向け出力側にはそれぞれの書式がある |
| MML オブジェクト | sxmml が音符、休符、コマンド等を表すために用いるオブジェクト。利用できる操作と制約は[要求仕様](requirements.md)に記す |
| ソースファイル | `sxlc` に渡す Gauche の Scheme ファイル。MML 文字列や sxmml の定義を含められる |
| `sxlc` | ソースファイルを読み込み、選択されたバックエンドで出力を生成するコマンド |
| バックエンド | sxmml 内で、処理した内容を対象の書式へ出力する部分。現在提供するのは PMD 向けの出力処理 |
| 生成物 | sxmml が変換の結果として作る成果物。現在は PMD 向け MML を生成する |
| PMD 向け MML | 現在のバックエンドが生成する、外部 PMD ツール向けのテキスト |
