= sxmml MML コマンドマニュアル
:toc: left

本書は通常 MML とリズム MML の書式を説明します。動作環境は Gauche 0.9.15 です。文字列は Scheme ソースの `(mml G "c8")` または `(rhythm L "@b8")` のように記述します。ソース中のマクロの使い方は xref:sxmml-reference-manual.adoc[MML 記述者向けリファレンス]、変換コマンドは link:sxlc.1.md[sxlc マニュアル]を参照してください。

以下の書式は sxmml が読み取る MML です。コマンドを使用できる音源や、生成時に受け付ける値の範囲はバックエンドによって異なります。
PMD 向けでは、反復回数とポルタメントの長さは 1～255、ポルタメント両端の音域は `o1c`～`o8b` です。pmd-source の反復の入れ子は最大32段です。PMD の検査範囲は xref:behavior-spec.adoc#pmd-source-の出力値の検査[外部動作仕様]、FMP7 と NSD.Lib での制約は各モードの節を参照してください。

== 共通の書き方

MML コマンドは前から順に処理され、空白を挟めます。多くの数値パラメータは `v8` または `v{8}` の形で指定できます。音符・休符の音長は波括弧で囲みません。リズム楽器を複数指定するときは `@bs8` または `@{bs}8` と書きます。

解像度の初期値は四分音符あたり 24 tick、既定の音長は四分音符、オクターブは 4 です。例えば `c8r8` は各 12 tick で合計 24 tick です。解像度を変更する場合は、ソースの先頭で `sxmml-resolution` を指定します。

=== 音長

音符と休符の後には、分母、付点、または `%tick数` を指定できます。分母 `n` は1以上の整数で、全音符の `1/n` の長さを表します。省略すると `l` で設定した長さです。付点は各段で半分の長さを加えます。多重付点は `c8..` のように続けて書き、付点の間に空白は入れません。解像度で表せない細分はエラーになります。

`&` に続けて分母または `%tick数` を指定すると、その長さを加算できます。加算指定は複数続けられます。解像度 24 では `c8&16` は 12 + 6 tick、`c8&16&%3` は 12 + 6 + 3 tick です。`%tick数` は tick 数を直接指定する書き方で、付点は付けられません。ポルタメントの音長も同じ書き方です。

既定音長 `l` の分母も1以上の整数です。`%tick数` には1以上の整数を十進数字で指定します。先頭の 0 は許され、`%01` は `%1`、`%00012` は `%12` と同じ長さです。`%0`、`%00` など値が 0 の指定は、通常 MML とリズム MML のどちらでもエラーです。加算する長さにも正の値が必要で、`c8&%00` はエラーです。符号や小数は指定できません。

== 通常 MML

`mml` で登録する文字列に使用します。PMD モードでは、A～F は FM、G～I は SSG、J は PCM 用のトラックとして登録されます。リズム用の L には `rhythm` を使用します。

=== 音符・休符と音高

[cols="1,2,3",options="header"]
|===
|書式 |用途 |例・制約

|`c d e f g a b`
|音符。音名の直後に半音記号を付けて、音高を半音単位で変化させられます。
|`c+8`、`d-4`、`c++8`。半音記号は複数続けられます。音名と記号の間に空白は入れません。

|`r`
|休符。音長指定は音符と同じです。
|`r8`、`r%12`。

|`/{開始音 終了音}長さ`
|指定した二つの音高と長さのポルタメント指定です。
|`/{c g}8`。波括弧内では `o`、`<`、`>` でオクターブを変更できます。滑らかな音高変化の実際の効果は生成先に依存します。ポルタメントを `mml-delay` の再発音元にする書き方はサポートしていません。

|`l分母`
|後続の音符・休符・ポルタメントの既定音長を設定します。
|`l8 c d`。初期値は 4 です。

|`o数値`、`>`、`<`
|オクターブの設定、1 上げる、1 下げる。
|`o4 > c < d`。`>` と `<` に引数はありません。実際に使用できる音域は生成先に依存します。

|`K符号付き整数`
|生成先へ移調指定を渡します。
|`K2 c`。

|`K*符号付き整数`
|現在の移調指定に対する相対変更を渡します。
|`K*-1 c`。反復中などで移調値を段階的に変える際に使えます。

|`K$符号付き整数`
|以後の音符の音高を sxmml 内で半音単位に移します。
|`K$2 c`。生成先への移調コマンドとしては出力されません。

|`D符号付き整数`
|発音周波数を調整するためのデチューン値を指定します。
|`D-2 c`。数値と音程の対応は生成先に依存します。
|===

=== 音量・定位・ゲート

[cols="1,2,3",options="header"]
|===
|書式 |用途 |例・制約

|`v数値`、`v*符号付き整数`
|音量の指定、現在値からの相対変更。
|`v8 c v*-2 d`。

|`)`、`(`
|トラックの音量変化幅だけ増加、減少。
|`v8 ) c ( d`。PMD モードの A～F の幅は 4、J は 16、その他は 1 です。

|`p数値`
|左右の出力位置を選ぶパン値を指定します。
|`p2 c`。値の意味は生成先に依存します。

|`q数値`
|ゲートタイムを指定します。
|`q4 c8`。実際のキーオフの時刻は生成先に依存します。

|`&`
|独立したタイ記号です。長さ指定の `&` と区別します。
|`c8 & c8`。音長の直後に `&8` と書くと、直前の音符への音長加算です。
|===

=== テンポ・音色・制御

`t数値`、`T数値`::
`t120` は四分音符を一拍とする BPM 指定です。例えば付点四分音符を一拍とする 6/8 拍子で 80 BPM なら、四分音符基準で `t120` と指定します。
+
PMD では `t` を Timer-B の値に換算し、`T` では Timer-B の値を直接指定します。FMP7 と NSD.Lib では両方とも BPM 指定です。

`@数値`、`@{名前}`::
+
--
音源に応じた音色や波形を選びます。数値だけの名前は `@0` のように、文字を含む名前は `@{tone}` のように書きます。

* PMD の FM では `define-opn-voice` で登録した音色を指定します。SSG では 0～9 の整数を使います。PCM・PPZ8 では `define-pcm-voice` の名前、または 0～255 の音色番号を使います。
* FMP7 では FM の音源に応じて `define-opn-voice` または `define-opm-voice` の名前を指定します。SSG にはプリセット、PCM には `define-pcm-voice` の名前を使います。
* NSD.Lib では、対応する音源に対してデューティ比、ノイズ周期、または登録済みの FDS 波形を選びます。

定義方法と例は xref:sxmml-reference-manual.adoc[MML 記述者向けリファレンス]を参照してください。
--

`E数値`、`E{名前}`::
`define-envelope` で登録したエンベロープを指定します。例えば `E1 c8`、`E{E1} c8` と書きます。値の形式と対応音源はバックエンドごとに異なります。

`M数値`、`M{名前 チャンネル}`::
`define-lfo` で登録した LFO を選びます。例えば `M1 c8`、`M{L1 B} c8` と書きます。名前を波括弧で指定する場合はチャンネルも書きます。
+
PMD4 では `A` または `B` を使えます。PMD3 バイナリは `B` を受け付けません。

`Mt`、`Mf`::
LFO をオン・オフにします。`Mt c8 Mf` では既定のチャンネルを、`Mt{B}` のように書くと指定のチャンネルを切り替えます。

`P数値`、`w数値`::
SSG のトーン・ノイズの選択とノイズ周波数を指定します。例えば `P1 w8 c8` と書きます。パラメータの意味と使用できる音源は出力先に従います。

=== ループ・反復

[cols="1,2,3",options="header"]
|===
|書式 |用途 |例・制約

|`L`
|ループ開始位置を示します。
|`c8 L d8`。sxmml は位置以後の tick 数も表示します。反復は同じ位置を何度も通り、戻り先を一つに決められないので、`L` は反復の外にだけ書けます。`[c8 L d8]2` は `loop command cannot be used inside repeats` で変換の失敗になります。

|`[本文]回数`
|指定回数の反復を表します。
|`[c8d8]2`。回数は正の整数を十進数字で書きます。`[c8d8]{2}` のように波括弧も使えます。`[c8d8]1` は `c8d8` と同じ意味です。回数0は変換の失敗になります。

|`[前半:後半]回数`
|最終回の脱出位置を含む反復を表します。
|`[c8:d8]2`。回数は正の正確な整数です。`[c8:d8]1` は `c8` と同じ意味で、回数0は変換の失敗になります。`:` は反復内で使い、一つの反復に一つだけ書けます。反復の後に続く `l` の既定音長、オクターブ、`K$` による音高移動は、`:` の位置での設定を引き継ぎます。
|===

脱出位置がない反復では、反復の末尾の既定音長・オクターブ・`K$` の設定を引き継ぎます。

通常 MML・リズム MML ともに、`L` は1トラックに1個までです。同じトラックへの複数回の `mml`・`rhythm` の登録にまたがる場合も、2個目は `loop command can be used only once in a track` で変換の失敗になります。別のトラックでは、それぞれ独立して `L` を使用できます。

== リズム MML

`rhythm` で登録する文字列に使用します。PMD モードでは L トラックがリズム用です。楽器記号は `b`（バス）、`s`（スネア）、`t`（タム）、`c`（シンバル）、`h`（ハイハット）、`i`（リムショット）で、一つ以上を連続して指定します。開き波括弧の後と閉じ波括弧の前には空白を入れられますが、楽器記号の間には入れません。例えば `@{bs}8` は使えますが、`@{b s}8` は構文エラーです。

[cols="1,2,3",options="header"]
|===
|書式 |用途 |例・制約

|`@楽器長さ`
|指定した楽器を発音し、指定した音長だけ進みます。
|`@b8`、`@{bs}8`。音長の書き方は通常 MML と同じです。

|`!楽器`
|指定楽器の発音停止を表します。
|`!b`、`!{bs}`。音長を取りません。

|`r長さ`
|休符を入れます。
|`r8`、`r%12`。

|`V数値`
|リズム全体の音量を指定します。
|`V10 @b8`。

|`v楽器 数値`
|楽器別の音量を指定します。
|`vb8 @b8`、`v{bs}8 @bs8`。

|`p楽器 数値`
|楽器別のパンを指定します。
|`pb2 @b8`。値の意味は生成先に依存します。

|`)楽器 符号付き整数`、`(楽器 符号付き整数`
|楽器別の音量を指定量だけ増減します。
|`)b1 @b8`、`(b1 @b8`。負数を与えると変化方向が逆になります。

|`l分母`
|既定音長を設定します。
|`l8 @b r`。

|`L`、`[本文]回数`、`[前半:後半]回数`
|ループと反復を指定します。
|`@b8 L [@s8r8]2`。`L` は通常 MML と同じく反復の外にだけ書けます。
|===

楽器記号は複数をまとめて指定できます。例えば `v{bs}8` はバスとスネアの両方へ音量値を指定します。`!{bs}` は同じ二楽器の発音停止を指定します。通常 MML の `o`、`v*`、`q` などはリズム MML のコマンドではありません。使用できる文字は通常 MML と異なります。

== 使用例

link:../README.md#最初の変換[README の導入手順]で `sxlc` をインストールしてください。次の内容を `commands.sxl` として保存し、`sxlc -m pmd commands.sxl` で変換します。

[source,scheme]
----
(mml G "l8 o4 c+ d- r8 [e f]2")
(rhythm L "V10 vb8 @b8 r8")
----

PMD 向けの `commands.mml` が生成され、G と L のトラック合計 tick 数が表示されます。

== FMP7 モード

SSG は `@{square}`、`@{triangle1}`・`@{triangle2}`、`@{pulse1}`～`@{pulse9}`、`@{sawtooth1}`・`@{sawtooth2}` でプリセットを選びます。`P1`～`P3` はトーン・ノイズの選択、`w0`～`w31` はノイズ周波数です。

SSG と PCM の `E` は、`default` が 6 値、`extended` が 13 値です。指定できる値はそれぞれ 0～255 です。

`M` で選ぶソフトウェアビブラートには、遅延（0～128）、速度（1～255）、変化量と深度（各 −32768～32767）の 4 値をこの順で指定します。5 つ目は同期（0 または 1、既定値 1）、6 つ目は補正（−32768～32767、既定値 0）で、末尾から省略できます。

波形は `default`、`triangle`、`saw`、`square`、`one-shot`、`random` です。チャンネルを省略すると `A` になります。`B`、`C`、`D` も使えます。全チャンネルのスイッチは最初から有効です。`M` はその状態を維持し、`Mt` は有効、`Mf` は無効にします。反復によって単独の `M` に有効・無効の両方で到達する場合は、直後に同チャンネルの明示スイッチが必要です。

分解能は 2～96、音長は 1～65535 ticks、音域は `o1c`～`o8b` です。`t`・`T` はともに BPM 6～400 です。`v` は 0～127、`p` は 1～255（中央 128）、`q` は 0～65535、`K`・`K*` は −96～96、`D` は −6144～6144 です。有限反復は 1～255 回、`L` はパートごとに有限反復の外で 1 箇所です。

== NSD.Lib の対応

トラックで最も多く登録された音長が 1～255 tick のとき、先頭に `l%N` を置き、同じ長さの音符・休符では音長を省略します。他の音長は tick 数で明記します。統計が空か最頻値が範囲外なら、すべての音長を明記します。

明示タイはその位置で出力し、255 tick を超える音符は末尾を 255 tick として同音をタイでつなぎます。`q` は 0～255 で、音長から短くする tick 数です。長休符も分割し、DPCM の休符はサンプルをキーオフします。

音域は出力側で `o1c`～`o8b`、`triangle` は記述音高に 1 オクターブ、`fds` は 2 オクターブ加算します。`noise` は元の音名を使い、周期は NSD.Lib のノート番号の下位 4 ビットで決まります。

ポルタメントは 1～255 tick です。nsc が滑り方の計算に使うテンポは、別トラックを含めファイル上で先に現れたテンポです。nsc v1.30 の計算では、同音間のポルタメントや換算結果が 0 フレームとなる短いポルタメントでゼロ除算が生じます。同じ音高を保つ場合は通常の音符を使用してください。

`t`・`T` はともに BPM で、BPM × 分解能 ÷ 24 の整数部分が 1～255 の場合に使えます。`K`・`K*` は絶対・相対移調、`D` は 16 で半音のデチューンで各 −128～127 です。DPCM に対する移調ではサンプル選択先も変わります。

`v` は 0～15、`v*` は相対音量、括弧による相対音量の既定変化幅は 1 です。`triangle`・`dpcm` は音量指定に対応しません。`p`、`P`、`w` は全対象音源でエラーです。

数値の `@` は `pulse` の 0～3、`vrc6-pulse` の 0～7 でデューティ比、`noise` の 0・1 で長周期・短周期を選びます。`fds` の `@` は登録した波形を選びます。`triangle`・`dpcm`・`vrc6-saw` の `@` はエラーです。

`E` は音量エンベロープを選びます。対象値は `pulse`・`noise`・`vrc6-pulse` で 0～15、`fds`・`vrc6-saw` で 0～63、`triangle` はリニアカウンターの 0～4 です。`dpcm` には `E` を使えません。

`M` はピッチエンベロープ（−64～63、16 で半音）を選び、既定チャンネルと `A` に対応します。初期スイッチは有効です。`Mf` 中の `M` は選択だけを更新し、次の `Mt` でその定義を有効にします。例えば `M0 Mf [Mt c8 Mf M1]2` は、同じ `Mt` の再開先が周回により異なり、一つの `Em` 番号では表せないためエラーです。

有限反復は 1～255 回で、1 回なら実行される部分だけを出力します。入れ子の内側は nsc の既定モードで展開されます。`L` は有限反復の外に各トラック最大 1 個です。sxmml の最適化レベルによらず整列済みの命令を使用します。
