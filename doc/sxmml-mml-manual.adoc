= sxmml MML コマンドマニュアル
:toc: left

本書は通常 MML とリズム MML の書式を説明します。動作環境は Gauche 0.9.15 です。文字列は Scheme ソースの `(mml G "c8")` または `(rhythm L "@b8")` のように記述します。ソース中のマクロの使い方は link:sxmml-reference-manual.adoc[MML 記述者向けリファレンス]、変換コマンドは link:sxlc.1.md[sxlc マニュアル]を参照してください。

MML コマンドは sxmml の生成物に反映されます。音源での音響効果や値の有効範囲は生成先のドライバーにも依存します。

== 共通の書き方

MML コマンドは前から順に処理され、空白を挟めます。多くの数値パラメータは `v8` または `v{8}` の形で指定できます。音符・休符の音長は波括弧で囲みません。リズム楽器を複数指定するときは `@bs8` または `@{bs}8` と書きます。

解像度の初期値は四分音符あたり 24 tick、既定の音長は四分音符、オクターブは 4 です。例えば `c8r8` は各 12 tick で合計 24 tick です。解像度はソース中の `sxmml-resolution` で変更できます。

=== 音長

音符と休符の後には、分母、付点、または `%tick数` を指定できます。分母 `n` は全音符の `1/n` の長さを表します。省略すると `l` で設定した長さです。付点は各段で半分の長さを加えます。多重付点は `c8..` のように続けて書き、付点の間に空白は入れません。解像度で表せない細分はエラーになります。

`&` に続けて分母または `%tick数` を指定すると、その長さを加算できます。加算指定は複数続けられます。解像度 24 では `c8&16` は 12 + 6 tick、`c8&16&%3` は 12 + 6 + 3 tick です。`%tick数` は tick 数を直接指定する書き方で、付点は付けられません。ポルタメントの音長も同じ書き方です。

分母 0 はエラーです。`%tick数` には正の整数を十進数字で指定します。先頭の 0 は許され、`%01` は `%1`、`%00012` は `%12` と同じ長さです。`%0`、`%00` など値が 0 の指定は、通常 MML とリズム MML のどちらでもエラーです。加算する長さにも正の値が必要で、`c8&%00` はエラーです。符号や小数は指定できません。

== 通常 MML

`mml` で登録する文字列に使用します。PMD モードでは、A～F は FM、G～I は SSG、J は PCM 用のトラックとして登録されます。リズム用の L には `rhythm` を使用します。

=== 音符・休符と音高

[cols="1,2,3",options="header"]
|===
|書式 |用途 |例・制約

|`c d e f g a b`
|音符。音名の直後に半音記号を付けて、音高を半音単位で変化させられます。
|`c+8`、`d-4`、`c++8`。半音記号は複数続けられます。音名と記号の間に空白は入れません。

|`r`
|休符。音長指定は音符と同じです。
|`r8`、`r%12`。

|`/{開始音 終了音}長さ`
|指定した二つの音高と長さのポルタメント指定です。
|`/{c g}8`。括弧内では `o`、`<`、`>` でオクターブを変更できます。滑らかな音高変化の実際の効果は生成先に依存します。

|`l分母`
|後続の音符・休符・ポルタメントの既定音長を設定します。
|`l8 c d`。初期値は 4 です。

|`o数値`、`>`、`<`
|オクターブの設定、1 上げる、1 下げる。
|`o4 > c < d`。`>` と `<` に引数はありません。向きを反転させる設定はありません。実際に使用できる音域は生成先に依存します。

|`K符号付き整数`
|生成先へ移調指定を渡します。
|`K2 c`。

|`K*符号付き整数`
|現在の移調指定に対する相対変更を渡します。
|`K*-1 c`。反復中などで移調値を段階的に変える際に使えます。

|`K$符号付き整数`
|以後の音符の音高を sxmml 内で半音単位に移します。
|`K$2 c`。生成先への移調コマンドとしては出力されません。

|`D符号付き整数`
|発音周波数を調整するためのデチューン値を指定します。
|`D-2 c`。数値と音程の対応は生成先に依存します。
|===

=== 音量・定位・ゲート

[cols="1,2,3",options="header"]
|===
|書式 |用途 |例・制約

|`v数値`、`v*符号付き整数`
|音量の指定、現在値からの相対変更。
|`v8 c v*-2 d`。

|`)`、`(`
|トラックの音量変化幅だけ増加、減少。
|`v8 ) c ( d`。PMD モードの A～F の幅は 4、J は 16、その他は 1 です。

|`p数値`
|左右の出力位置を選ぶパン値を指定します。
|`p2 c`。値の意味は生成先に依存します。

|`q数値`
|ゲートタイムを指定します。
|`q4 c8`。実際のキーオフの時刻は生成先に依存します。

|`&`
|独立したタイ記号です。長さ指定の `&` と区別します。
|`c8 & c8`。音長の直後に `&8` と書くと、直前の音符への音長加算です。
|===

=== テンポ・音色・制御

[cols="1,2,3",options="header"]
|===
|書式 |用途 |例・制約

|`t数値`、`T数値`
|それぞれ BPM 指定、生成先向けのテンポ値を直接指定。
|`t120 c8`、`T200 c8`。`t` の 1 拍は四分音符として扱います。6/8 拍子などで四分音符以外を 1 拍と数えるときは、数えたい拍数を四分音符基準に換算して指定します。PMD モードでは `t` をタイマー値に変換し、`T` は値を直接出力します。実際の演奏速度は生成先に依存します。

|`@数値`、`@{名前}`
|音色を指定します。
|`@0 c8`、`@{tone} c8`。波括弧なしでは数字だけを受けます。FM トラックでは対応する音色を `define-opn-voice` で先に定義する必要があります。SSG/PCM では数値指定を使用し、PMD モードでは SSG が 0～9、PCM が 0～255 の整数です。

|`E数値`、`E{名前}`
|音量の時間変化に用いるエンベロープ定義を選びます。
|`E1 c8`、`E{E1} c8`。波括弧なしでは数字だけを受けます。`define-envelope` の定義値が必要です。

|`M数値`、`M{名前 チャンネル}`
|定義した LFO を指定します。
|`M1 c8`、`M{L1 B} c8`。波括弧なしでは数字だけを受けます。名前を使う波括弧形にはチャンネルも必要です。PMD モードのチャンネルは `A` または `B` です。`define-lfo` の定義値が必要です。LFO のオン・オフは `Mt` / `Mf` で別に指定します。

|`Mt`、`Mf`
|既定チャンネルの LFO をオン、オフにします。
|`Mt c8 Mf`。チャンネルは `Mt{B}`、`Mf{B}` のようにも指定できます。

|`P数値`、`w数値`
|SSG のトーン・ノイズ・ミックスの選択値、ノイズ周波数の値を指定します。
|`P1 w8 c8`。値の具体的な音響効果は生成先に依存します。
|===

=== ループ・反復

[cols="1,2,3",options="header"]
|===
|書式 |用途 |例・制約

|`L`
|ループ開始位置を示します。
|`c8 L d8`。sxmml は位置以後の tick 数も表示します。

|`[本文]回数`
|指定回数の反復を表します。
|`[c8d8]2`。

|`[前半:後半]回数`
|最終回の脱出位置を含む反復を表します。
|`[c8:d8]2`。`:` は反復内で使います。反復の後に続く `l` の既定音長、オクターブ、`K$` による音高移動は、`:` の位置での設定を引き継ぎます。
|===

`L` はループ位置、`[` と `]` は回数付き反復を表します。`:` は最終回に後半を飛ばす位置です。

== リズム MML

`rhythm` で登録する文字列に使用します。PMD モードでは L トラックがリズム用です。楽器記号は `b`（バス）、`s`（スネア）、`t`（タム）、`c`（シンバル）、`h`（ハイハット）、`i`（リムショット）で、一つ以上を連続して指定します。開き波括弧の後と閉じ波括弧の前には空白を入れられますが、楽器記号の間には入れません。例えば `@{bs}8` は使えますが、`@{b s}8` は構文エラーです。

[cols="1,2,3",options="header"]
|===
|書式 |用途 |例・制約

|`@楽器長さ`
|指定楽器の発音と長さを指定します。
|`@b8`、`@{bs}8`。音長の書き方は通常 MML と同じです。

|`!楽器`
|指定楽器の発音停止を表します。
|`!b`、`!{bs}`。音長を取りません。

|`r長さ`
|休符を入れます。
|`r8`、`r%12`。

|`V数値`
|リズム全体の音量を指定します。
|`V10 @b8`。

|`v楽器 数値`
|楽器別の音量を指定します。
|`vb8 @b8`、`v{bs}8 @bs8`。

|`p楽器 数値`
|楽器別のパンを指定します。
|`pb2 @b8`。値の意味は生成先に依存します。

|`)楽器 符号付き整数`、`(楽器 符号付き整数`
|楽器別の音量を指定量だけ増減します。
|`)b1 @b8`、`(b1 @b8`。負数を与えると変化方向が逆になります。

|`l分母`
|既定音長を設定します。
|`l8 @b r`。

|`L`、`[本文]回数`、`[前半:後半]回数`
|ループと反復を指定します。
|`@b8 L [@s8r8]2`。
|===

楽器記号は複数をまとめて指定できます。例えば `v{bs}8` はバスとスネアの両方へ音量値を指定します。`!{bs}` は同じ二楽器の発音停止を指定します。通常 MML の `o`、`v*`、`q` などはリズム MML のコマンドではありません。使用できる文字は通常 MML と異なります。

== 使用例

link:../README.md#最初の変換[README の導入手順]で `sxlc` をインストールしてください。次の内容を `commands.sxl` として保存し、`sxlc -m pmd commands.sxl` で変換します。

[source,scheme]
----
(mml G "l8 o4 c+ d- r8 [e f]2")
(rhythm L "V10 vb8 @b8 r8")
----

PMD 向けの `commands.mml` が生成され、G と L のトラック合計 tick 数が表示されます。
