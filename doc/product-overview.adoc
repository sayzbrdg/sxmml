= sxmml 製品概要・用語集

sxmml の動作環境は Gauche 0.9.15 です。

[[製品の目的と利用場面]]
== 製品の目的と利用場面

sxmml は、Gauche の Scheme で楽曲を記述できる MML トランスレータです。
フレーズを手続きで組み立てたり、同じフレーズを複数のトラックで使ったりできます。
これまで手作業で行っていた命令の整理や反復への書き換えも、出力モードに応じて自動化できます。

. Scheme のソースファイルに、`mml` や `rhythm` で楽曲を記述します。
. `sxlc` で変換します。出力モードはコマンドの `-m` で指定するか、ソース内で選択できます。
. 生成した MML を対象のコンパイラに渡すか、直接生成したバイナリを対応するドライバーで演奏します。

[[機能と責任の境界]]
== 出力形式

[cols="2,2,1",options="header"]
|===
|生成物 |モード指定の例 |既定の拡張子
|PMD 向け MML |`-m pmd`（PMD4）、`-m pmd3`（PMD3） |`.mml`
|PMD バイナリ |`-m pmd-binary`（PMD4）、`-m pmd3-binary`（PMD3） |`.m`
|FMP7 向け MML |`-m fmp7` |`.mwi`
|NSD.Lib 向け MML |`-m nsdlib` |`.nsd`
|===

`-O` で指定した最適化レベルに対して、どの処理を適用するかはバックエンドが決めます。最適化の目的と評価基準は xref:requirements.adoc[要求仕様]を参照してください。

[[責任範囲]]
== 責任範囲

sxmml は、選択したバックエンドで楽曲を変換し、生成物を出力します。
PMD バイナリは sxmml が直接生成します。MC.EXE が生成するバイナリとの一致は保証しません。

生成した MML のコンパイルには、対象の外部コンパイラを使います。
`sxlc -c` を指定すると、生成後に外部コマンドを起動して出力ファイルを渡せます。
MML を受理するかどうかは外部コンパイラが判定し、楽曲の演奏は各音源ドライバーが行います。

[[用語]]
== 用語

[cols="1,1",options="header"]
|===
|用語 |本書での意味
|MML |音符、音長、音量などを文字で記す楽曲記述。sxmml の入力と各バックエンドの出力には、それぞれの書式がある
|MML オブジェクト |sxmml が音符、休符、コマンド等を表すために用いるオブジェクト。利用できる操作と制約はxref:requirements.adoc[要求仕様]に記す
|ソースファイル |`sxlc` に渡す Gauche の Scheme ファイル。MML 文字列や sxmml の定義を含められる
|`sxlc` |ソースファイルを読み込み、選択されたバックエンドで出力を生成するコマンド
|バックエンド |sxmml 内で、処理した内容を対象の書式へ出力する部分。
|生成物 |バックエンドが楽曲を変換して得られるファイル。形式は <<機能と責任の境界,出力形式>> を参照
|PMD 向け MML |現在のバックエンドが生成する、外部 PMD ツール向けのテキスト
|===
